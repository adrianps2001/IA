Parte 1 · 10 %

Lo que debes saber como creador de Roblox

La plataforma, cómo se divide el trabajo entre cliente y servidor, cómo se guardan datos, cómo se gana dinero y qué reglas hay que respetar para publicar sin problemas.

1.1 Cómo funciona Roblox por dentro

Un juego de Roblox (oficialmente una experiencia) es un árbol de objetos llamado DataModel, al que el código accede como game. Cada objeto es una Instance: una pieza (Part), una carpeta (Folder), un script, un sonido… Las ramas principales del árbol son servicios, y cada uno tiene una función:

ReplicatedStorageCosas compartidas que no están en el mundoServidor y clientesShared (módulos comunes), Remotes, RoundState
ServerScriptServiceScripts del servidorSolo el servidorServer y sus 10 servicios
StarterPlayer › StarterPlayerScriptsScripts que se copian a cada jugadorCada clienteClient y sus controladores
PlayersUn objeto Player por cada persona conectadaAmbosAtributos como Heat, Coins, IsCarrier

🖥️ Script

Se ejecuta en el servidor. Aquí vive la verdad del juego: dinero, robos, quién gana.

📱 LocalScript

Se ejecuta en el dispositivo de cada jugador: interfaz, cámara, efectos y controles.

🧩 ModuleScript

Código reutilizable que no se ejecuta solo: otros scripts lo cargan con require. Casi todo este proyecto son módulos.

1.2 Cliente y servidor: la regla de oro

Cada partida corre en un servidor de Roblox al que se conectan hasta N jugadores (aquí, ). Lo que cambia el servidor se replica a los clientes. Lo que cambia un cliente no llega a los demás, salvo la física de su propio personaje. Para comunicarse se usan RemoteEvents (mensajes) y RemoteFunctions (preguntas con respuesta).

Nunca te fíes del cliente. Hay jugadores que modifican su cliente para hacer trampas: pueden enviar cualquier mensaje, a cualquier ritmo y con cualquier dato. Por eso en este proyecto el cliente solo pide cosas ("quiero robar", "quiero mejorar la bolsa"). El servidor comprueba la distancia, el tiempo, las Monedas y la fase antes de hacer nada. Un ejemplo: el robo exige mantener la tecla 1,5 s, y es el servidor quien mide ese tiempo.

Además, con StreamingEnabled (activado en este proyecto) el cliente solo carga las partes del mundo que tiene cerca. Por eso el código del cliente usa FindFirstChild y comprueba si algo existe antes de usarlo.

1.3 Guardar datos

💾 DataStoreService

Almacén permanente de clave-valor. Aquí, una clave por jugador (player_<UserId>). Tiene límites de peticiones por minuto y de tamaño por clave, así que se guarda en lotes (autosave cada s).

🔒 UpdateAsync

Lee y escribe de forma atómica, y permite cancelar la escritura. Es la base del bloqueo de sesión que evita duplicar criaturas al saltar de servidor.

📡 MessagingService

Mensajes entre servidores del mismo juego. Aquí se usa para el aviso global de las criaturas Míticas y Secretas.

⚡ MemoryStoreService

Datos temporales y muy rápidos compartidos entre servidores (colas, rankings). Está previsto para el ranking semanal y el Huevo Comunitario.

En Studio los DataStores solo funcionan si activas Game Settings → Security → Enable Studio Access to API Services. Si no, DataService lo detecta y juega en memoria.

1.5 Cómo se gana dinero en Roblox

Todo se cobra en Robux. De las ventas de pases y productos dentro del juego, el creador recibe aproximadamente el 70 % y Roblox se queda el resto. Los Robux ganados se pueden cambiar por dinero real con DevEx (Developer Exchange), que pide unos requisitos mínimos. El tipo de cambio y los requisitos están en el Creator Hub y cambian con el tiempo, así que consúltalos siempre ahí.

1.6 Reglas y políticas que afectan al diseño

🎲 Objetos aleatorios de pago

Si se paga por algo aleatorio (un huevo), hay que mostrar las probabilidades antes de comprar. La tienda las calcula con Rarity.chances. Además, en algunos países están restringidos: MonetizationService pregunta a PolicyService y la tienda los oculta a quien no pueda comprarlos.

🧒 Público joven

Todo el texto que escriban los jugadores debe pasar por el filtro de Roblox (el chat oficial ya lo hace). No se pueden pedir datos personales. El GDD evita la violencia: robar es tocar y mantener, nunca pegar.

🏷️ Etiqueta de madurez

Antes de publicar se rellena el cuestionario de contenido del Creator Hub, que asigna la etiqueta de edad que verán los jugadores.

🚫 Prohibido

Miniaturas engañosas o promesas de "Robux gratis", mandar a pagar fuera de Roblox y copiar personajes o marcas de otros (ya hay demandas por clones).

⚖️ Monetización ética (GDD 9.6)

Ninguna compra garantiza ser elegido ni ganar la persecución. El Escudo está limitado a 1 por ronda y las Secretas no se pueden forzar con la Ofrenda Dorada.

📜 Normas de la comunidad

Las Community Standards y los Terms of Use se aplican a todo: nombres, imágenes, textos y anuncios del juego.

1.7 Descubrimiento y métricas

Roblox recomienda juegos según cómo se comportan sus jugadores: si vuelven al día siguiente, cuánto juegan y si les gusta. Según el GDD, en 2026 pesa sobre todo la retención a largo plazo. Por eso este diseño tiene un nido que produce aunque no estés, misiones diarias y racha.

2.3 Cómo arranca el juego

Todos los servicios siguen el mismo contrato: init() prepara lo suyo sin esperar a nada y start() conecta eventos y lanza bucles. Primero se llama a init() en todos y después a start() en todos. Así, cuando un servicio arranca, los demás ya están preparados.

--!strict

local services = {
	require(script.Services.DataService),
	require(script.Services.AnnouncementService),
	require(script.Services.MonetizationService),
	require(script.Services.MapService),
	require(script.Services.QuestService),

	service.init()
end

end

2.4 Quién usa a quién

Las flechas indican "usa a". No hay ciclos: un módulo nunca depende, ni directa ni indirectamente, de otro que dependa de él. Si hiciera falta, se usa un callback, como QuestService.onStreakReward, que lo rellena NestService.

2.5 Cómo viaja la información

🏷️ Atributos

Pequeños valores colgados de un objeto que se replican solos. El servidor escribe player:SetAttribute("Heat", 35) y el HUD escucha el cambio. Se usan para la bolsa, las Monedas, el portador y el estado de la ronda.

📨 RemoteEvent

Mensajes puntuales. Del servidor al cliente: HatchSequence, Notify. Del cliente al servidor: RequestSprint, RequestBreed.

❓ RemoteFunction

Pregunta con respuesta. Solo GetProfile, que va del cliente al servidor y es seguro. Al revés, del servidor al cliente, sería peligroso: un cliente podría no responder nunca y dejar al servidor esperando.

👆 ProximityPrompt

El botón de "mantén E" que aparece al acercarte a algo. Roblox comprueba la distancia, y este proyecto además valida el tiempo de pulsación en el servidor.

4.2 Rarity.luau · las seis rarezas

Cada rareza tiene un nivel (1–6), un peso sobre 1.000.000, su producción base y su color. Los colores son el lenguaje visual del GDD: gris, verde, azul, morado, naranja y rojo. La tirada funciona así: se suman los pesos permitidos, se elige un punto al azar en ese total y se recorre la lista restando pesos hasta que el punto "cae" dentro de una rareza.

-- Elige una rareza. La suerte multiplica el peso de todo lo que no es Común;
-- minRarity y maxRarity recortan el rango posible.
function Rarity.roll(rng: () -> number, luck: number?, minRarity: RarityName?, maxRarity: RarityName?): RarityName
	local luckValue = math.max(luck or 1, 0)
	local minTier = if minRarity then Rarity.tier(minRarity) else 1
	local maxTier = if maxRarity then Rarity.tier(maxRarity) else #Rarity.Order

	local total = 0
	local weights = {}
	for _, name in Rarity.Order do
		local info = Rarity.Info[name]
		local weight = 0
		if info.Tier >= minTier and info.Tier <= maxTier then
			weight = info.Weight * (if info.Tier > 1 then luckValue else 1)
		end
		weights[name] = weight
		total += weight
	end

	if total <= 0 then
		return Rarity.fromTier(minTier)
	end

	local pick = rng() * total
	for _, name in Rarity.Order do
		pick -= weights[name]
		if pick < 0 then
			return name
		end
	end
	return Rarity.fromTier(maxTier)
end

La suerte multiplica el peso de todo lo que no es Común, así que aumenta las probabilidades de todas las rarezas a la vez. minRarity y maxRarity recortan el rango; así es como los umbrales de la barra garantizan, por ejemplo, "mínimo Épica".

Cada criatura tiene cinco ranuras: Cuerpo, Cabeza, Patrón, Aura y Mutación. Cada ranura tiene 12 genes de distintas rarezas. Una criatura se guarda solo como cinco identificadores ("body_crystal", "head_beak"…), lo que ahorra memoria y espacio en el DataStore. Su rareza es la de su gen más raro.

Para generar una criatura de rareza exacta R, rollSet elige una ranura al azar para el gen firma, que tiene exactamente esa rareza. El resto de ranuras se tiran con rareza igual o menor. Así la criatura sale con la rareza pedida y el reparto de genes sigue siendo variado.

-- Genera los genes de una criatura de rareza exacta `rarity`: una ranura recibe un gen
-- de esa rareza (el "gen firma") y el resto se tira con rareza igual o menor.
function Genes.rollSet(rng: () -> number, rarity: RarityName, biases: Biases?): GeneSet
	local tier = Rarity.tier(rarity)
	local signatureSlots: { Slot } = {}
	for _, slot in Genes.Slots do
		if #genesOfTier(slot, tier) > 0 then
			table.insert(signatureSlots, slot)
		end
	end

	local signatureSlot = signatureSlots[math.floor(rng() * #signatureSlots) + 1] or signatureSlots[1]
	local result = {}
	for _, slot in Genes.Slots do
		if slot == signatureSlot then
			local biasId = biases and biases[slot]
			local biased = biasId and Genes.ById[biasId]
			if biased and biased.Slot == slot and biased.Rarity == rarity and rng() < Genes.BiasChance then
				result[slot] = biased.Id
			else
				result[slot] = pickFrom(genesOfTier(slot, tier), rng).Id
			end
		else
			result[slot] = Genes.rollSlot(slot, rng, rarity, biases and biases[slot])
		end
	end
	return result :: any
end
-- Gen aleatorio de una ranura con rareza como mucho maxRarity.
function Genes.rollSlot(slot: Slot, rng: () -> number, maxRarity: RarityName, biasGeneId: string?): string
	local maxTier = Rarity.tier(maxRarity)
	if biasGeneId then
		local biased = Genes.ById[biasGeneId]
		if biased and biased.Slot == slot and Rarity.tier(biased.Rarity) <= maxTier and rng() < Genes.BiasChance then
			return biased.Id
		end
	end

	local tier = Rarity.tier(Rarity.roll(rng, 1, nil, maxRarity))
	while tier >= 1 do
		local candidates = genesOfTier(slot, tier)
		if #candidates > 0 then
			return pickFrom(candidates, rng).Id
		end
		tier -= 1
	end
	return Genes.BySlot[slot][1].Id
end

Ofrendas. Los objetos del mapa favorecen un gen concreto: si su rareza cabe en la tirada, hay un 50 % de probabilidad (Genes.BiasChance) de que salga ese gen. Así los veteranos pueden "dirigir" la criatura sin garantizarla.

Herencia en la cría. Cada ranura del hijo copia el gen de uno de los padres al 50 %. Con un 10 % de probabilidad, la ranura muta: se vuelve a tirar con rareza máxima un nivel por encima del mejor padre (hasta Mítica). Las Secretas nunca salen de la cría.

-- Cría: cada ranura hereda de uno de los padres; con mutationChance se vuelve a tirar
-- con rareza máxima un nivel por encima del mejor padre (GDD 5.7).
function Genes.inherit(a: GeneSet, b: GeneSet, rng: () -> number, mutationChance: number): GeneSet
	local parentRarity = Rarity.max(Genes.rarityOf(a), Genes.rarityOf(b))
	local mutationCap = Rarity.fromTier(math.min(Rarity.tier(parentRarity) + 1, Rarity.tier("Mythic")))
	local child = {}
	for _, slot in Genes.Slots do
		if rng() < mutationChance then
			child[slot] = Genes.rollSlot(slot, rng, mutationCap)
		else
			child[slot] = if rng() < 0.5 then (a :: any)[slot] else (b :: any)[slot]
		end
	end
	return child :: any
end

4.5 Election.luau · a quién elige el huevo

La regla del GDD: probabilidad = tu Afinidad / Afinidad total, pero nadie baja del 2 %. Así siempre puede salir el clip de "no puse nada y me eligió". Para que todo sume 100 %, el algoritmo funciona en varias pasadas:

  1. Reparte la probabilidad en proporción a la Afinidad.
  2. A quien le toque menos del mínimo, se le fija exactamente el mínimo.
  3. Lo que queda se reparte otra vez entre los que no están fijados, en proporción a su Afinidad.
  4. Repite hasta que nadie quede por debajo.
function Election.chances(entries: { Entry }, minChance: number): { [string]: number }
	local result: { [string]: number } = {}
	local count = #entries
	if count == 0 then
		return result
	end

	local function minOf(entry: Entry): number
		return entry.Min or minChance
	end

	-- Si los mínimos no caben, se reparte en proporción a ellos.
	local totalMin = 0
	for _, entry in entries do
		totalMin += minOf(entry)
	end
	if totalMin >= 1 then
		for _, entry in entries do
			result[entry.Key] = if totalMin > 0 then minOf(entry) / totalMin else 1 / count
		end
		return result
	end

	local pinned: { [string]: boolean } = {}
	while true do
		local freeMass = 1
		local freeAffinity = 0
		local freeCount = 0
		for _, entry in entries do
			if pinned[entry.Key] then
				freeMass -= minOf(entry)
			else
				freeAffinity += math.max(entry.Affinity, 0)
				freeCount += 1
			end
		end

		local changed = false
		for _, entry in entries do
			if not pinned[entry.Key] then
				local share = if freeAffinity > 0
					then freeMass * math.max(entry.Affinity, 0) / freeAffinity
					else freeMass / freeCount
				if share < minOf(entry) then
					pinned[entry.Key] = true
					changed = true
				else
					result[entry.Key] = share
				end
			end
		end

		if not changed then
			break
		end
	end

	for key in pinned do
		for _, entry in entries do
			if entry.Key == key then
				result[key] = minOf(entry)
			end
		end
	end
	return result
end

Si los mínimos no caben (más de 50 jugadores con el 2 %), la probabilidad se reparte en proporción a ellos. Si nadie ha depositado nada, todos reciben lo mismo.

Suerte acumulada. Cada jugador puede traer su propio mínimo (Min). RoundService lo calcula con pityMin según cuántas rondas lleva sin ser elegido (Stats.RoundsSinceChosen): +2 % por ronda, hasta un 12 %. El simulador mostró que, sin esto, muchos novatos pasaban su primera semana sin vivir el momento de "¡me eligió!". En su primera ronda un novato ya tiene ese 12 % (Election.minFor).

Varios elegidos. Con varias criaturas, pickMany elige uno, lo quita de la lista, recalcula las probabilidades del resto y vuelve a elegir. Nadie puede llevarse dos criaturas en la misma eclosión.

-- Varios elegidos sin repetir (una criatura para cada uno). Tras cada elección se quita al
-- elegido y se recalculan las probabilidades del resto. Devuelve las claves en orden y las
-- probabilidades de la primera tirada (las que se enseñan en la ruleta).
function Election.pickMany(entries: { Entry }, minChance: number, count: number, rng: () -> number): ({ string }, { [string]: number })
	local remaining = table.clone(entries)
	local picked: { string } = {}
	local firstChances = Election.chances(entries, minChance)
	for _ = 1, math.min(count, #entries) do
		local key = Election.pick(remaining, minChance, rng)
		if not key then
			break
		end
		table.insert(picked, key)
		for i, entry in remaining do
			if entry.Key == key then
				table.remove(remaining, i)
				break
			end
		end
	end
	return picked, firstChances
end
-- Mínimo de un jugador que lleva roundsSinceChosen rondas sin ser elegido.
function Election.pityMin(roundsSinceChosen: number): number
	local e = Config.Election
	return math.min(e.MinChance + e.PityPerRound * math.max(roundsSinceChosen, 0), math.max(e.PityMaxChance, e.MinChance))
end

	end
	return math.floor(def.BaseCost * def.Growth ^ currentLevel * Config.PriceScale)
end

Todos los jugadores tienen las mismas 3 misiones cada día, sin guardar nada en ningún servidor. El truco es usar el número de día (días UTC desde 1970) como semilla de un generador pseudoaleatorio, que baraja la lista de misiones siempre igual para ese día.

-- Generador congruencial simple: misma selección para un día dado.
local function seededOrder(day: number, count: number): { number }
	local order = {}
	for i = 1, count do
		order[i] = i
	end
	local state = (day * 1103515245 + 12345) % 2147483648
	for i = count, 2, -1 do
		state = (state * 1103515245 + 12345) % 2147483648
		local j = (state % i) + 1
		order[i], order[j] = order[j], order[i]
	end
	return order
end

-- Renueva misiones si cambió el día y actualiza la racha. Devuelve true si la racha
-- acaba de completarse (día 7), para entregar el huevo especial.
function Quests.rollover(state: QuestState, today: number): boolean
	if state.Day ~= today then
		state.Day = today
		state.List = Quests.forDay(today)
	end
	if state.StreakDay == today then
		return false
	end
	if state.StreakDay == today - 1 then
		state.Streak += 1
	else
		state.Streak = 1
	end
	state.StreakDay = today
	if state.Streak >= Config.Quests.StreakDays then
		state.Streak = 0
		return true
	end
	return false
end
-- Suma progreso. Devuelve cuántas misiones se completaron con este avance.
function Quests.progress(state: QuestState, kind: QuestKind, amount: number): number
	local completed = 0
	for _, quest in state.List do
		if quest.Kind == kind and not quest.Claimed then
			local before = quest.Progress
			quest.Progress = math.min(quest.Goal, quest.Progress + amount)
			if before < quest.Goal and quest.Progress >= quest.Goal then
				quest.Claimed = true
				completed += 1
			end
		end
	end
	return completed
end

-- Rellena campos que falten y descarta datos corruptos sin perder lo válido.
function PlayerData.reconcile(raw: any, now: number): Profile
	local profile = PlayerData.default(now)
	if type(raw) ~= "table" then
		return profile
	end

	profile.Coins = math.max(number(raw.Coins, 0), 0)
	profile.Dust = math.max(number(raw.Dust, 0), 0)
	profile.Generation = math.max(math.floor(number(raw.Generation, 0)), 0)
	profile.LastSeen = number(raw.LastSeen, now)

	if type(raw.Upgrades) == "table" then
		for name in profile.Upgrades do
			profile.Upgrades[name] = math.max(math.floor(number(raw.Upgrades[name], 0)), 0)
		end
	end

	if type(raw.Stats) == "table" then
		for _, name in PlayerData.StatNames do
			profile.Stats[name] = math.max(number(raw.Stats[name], 0), 0)
		end
	end

	if type(raw.Creatures) == "table" then
		for _, creature in raw.Creatures do
			if Creature.isValid(creature) then
				-- La rareza siempre se recalcula a partir de los genes.
				creature.Rarity = Genes.rarityOf(creature.Genes)
				table.insert(profile.Creatures, creature)
			end
		end
	end

	if type(raw.Incubator) == "table" then
		for _, egg in raw.Incubator do
			if
				type(egg) == "table"
				and type(egg.Id) == "string"
				and type(egg.Kind) == "string"
				and Rarity.isValid(egg.MinRarity)
				and Rarity.isValid(egg.MaxRarity)
				and (egg.Genes == nil or Genes.isValidSet(egg.Genes))
			then
				egg.ReadyAt = number(egg.ReadyAt, now)
				table.insert(profile.Incubator, egg)
			end
		end
	end

	local q = raw.Quests
	if type(q) == "table" and type(q.List) == "table" then
		profile.Quests.Day = math.floor(number(q.Day, profile.Quests.Day))
		profile.Quests.StreakDay = math.floor(number(q.StreakDay, -1))
		profile.Quests.Streak = math.floor(number(q.Streak, 0))
		local list = {}
		for _, quest in q.List do
			if type(quest) == "table" and type(quest.Kind) == "string" then
				table.insert(list, {
					Kind = quest.Kind,
					Goal = math.max(number(quest.Goal, 1), 1),
					Progress = math.max(number(quest.Progress, 0), 0),
					Claimed = quest.Claimed == true,
				})
			end
		end
		if #list > 0 then
			profile.Quests.List = list
		end
	end

	if type(raw.Receipts) == "table" then
		for _, receipt in raw.Receipts do
			if type(receipt) == "string" then
				table.insert(profile.Receipts, receipt)
			end
		end
	end

	if type(raw.LastBreed) == "table" and type(raw.LastBreed[1]) == "string" and type(raw.LastBreed[2]) == "string" then
		profile.LastBreed = { raw.LastBreed[1], raw.LastBreed[2] }
	end

	if type(raw.Funnel) == "table" then
		for key, value in raw.Funnel do
			if type(key) == "string" and value == true then
				profile.Funnel[key] = true
			end
		end
	end

	if type(raw.Decorations) == "table" then
		for _, id in raw.Decorations do
			if type(id) == "string" and not table.find(profile.Decorations, id) then
				table.insert(profile.Decorations, id)
			end
		end
	end

	local community = raw.Community
	if type(community) == "table" and type(community.Month) == "string" then
		profile.Community = {
			Month = community.Month,
			Heat = math.max(number(community.Heat, 0), 0),
			Claimed = community.Claimed == true,
		}
	end

	if type(raw.Trades) == "table" then
		for _, record in raw.Trades do
			if type(record) == "table" and type(record.WithName) == "string" and type(record.Gave) == "table" and type(record.Got) == "table" then
				table.insert(profile.Trades, {
					With = number(record.With, 0),
					WithName = record.WithName,
					Gave = strings(record.Gave),
					Got = strings(record.Got),
					At = number(record.At, 0),
				})
			end
		end
	end

	-- Favoritas: solo ids de criaturas que existen, sin repetir y como mucho Config.Favorites.Max.
	if type(raw.Favorites) == "table" then
		for _, id in raw.Favorites do
			if type(id) == "string" and not table.find(profile.Favorites, id) and #profile.Favorites < Config.Favorites.Max and PlayerData.findCreature(profile, id) then
				table.insert(profile.Favorites, id)
			end
		end
	end

	local likes = raw.Likes
	if type(likes) == "table" and type(likes.Week) == "string" and type(likes.Given) == "table" then
		local given = {}
		for _, userId in likes.Given do
			if type(userId) == "number" then
				table.insert(given, userId)
			end
		end
		profile.Likes = { Week = likes.Week, Given = given }
	end

	return profile
end

-- ¿Es válido un robo? holdStartedAt es cuándo empezó el tira y afloja (medido por el
-- servidor), immuneUntil hasta cuándo es inmune el portador y distance la separación actual.
function ChaseRules.canSteal(now: number, holdStartedAt: number?, immuneUntil: number, distance: number): StealCheck
	if not holdStartedAt then
		return "noHold"
	end
	if now - holdStartedAt < ChaseRules.holdTime() - ChaseRules.HoldTolerance then
		return "tooShort"
	end
	if now < immuneUntil then
		return "immune"
	end
	if distance > Config.Chase.StealRange + ChaseRules.DistanceTolerance then
		return "tooFar"
	end
	return "ok"
end

function Rewards.compute(participants: { Participant }, outcomes: { Outcome }): { [string]: Reward }
	local result: { [string]: Reward } = {}
	local byKey: { [string]: Participant } = {}
	for _, p in participants do
		byKey[p.Key] = p
		result[p.Key] = {
			Dust = if isActive(p) then Economy.consolationDust(p.Affinity, p.StealAttempts) else 0,
			Won = {},
			Copies = {},
			ChosenEgg = false,
		}
	end

	for index, outcome in outcomes do
		local winner = outcome.Winner
		local winnerReward = if winner then result[winner] else nil
		if winner and winnerReward then
			table.insert(winnerReward.Won, index)
			-- El ganador cobra el bonus; sus aliados, una parte de su polvo y una copia.
			local p = byKey[winner]
			local winnerDust = Config.Consolation.WinnerBonusDust + Economy.consolationDust(p.Affinity, p.StealAttempts)
			winnerReward.Dust += Config.Consolation.WinnerBonusDust
			for _, partner in outcome.Partners do
				local reward = result[partner]
				if reward and partner ~= winner then
					reward.Dust += math.floor(winnerDust * Config.Deal.DustShare)
					table.insert(reward.Copies, index)
				end
			end
		end
		-- Ser elegido siempre tiene que sentirse bien, aunque te la roben.
		local chosen = outcome.Chosen
		local chosenReward = if chosen then result[chosen] else nil
		if chosen and chosenReward and chosen ~= winner then
			chosenReward.Dust += Config.Consolation.ChosenBonusDust
			chosenReward.ChosenEgg = chosenReward.ChosenEgg or Config.Consolation.ChosenEgg
		end
	end
	return result
end

-- Puntos de la rampa en espiral: uno por tablón, desde el suelo hasta la plataforma más alta.
function ArenaLayout.rampPoints(tree: Tree, start: number?): { Vec }
	local radius = ArenaLayout.rampRadius(tree)
	local top = tree.Decks[#tree.Decks]
	local segment = radius * ArenaLayout.RampStep
	local rise = segment * math.tan(ArenaLayout.RampSlope)
	local count = math.ceil(top / rise)
	rise = top / count -- termina justo a la altura de la plataforma
	local angle0 = start or tree.RampStart
	local points: { Vec } = {}
	for i = 0, count do
		local angle = angle0 + i * ArenaLayout.RampStep
		table.insert(points, { X = tree.X + math.cos(angle) * radius, Y = i * rise, Z = tree.Z + math.sin(angle) * radius })
	end
	return points
end

ArenaLayout describe el parkour con números: dónde está cada árbol, a qué alturas tiene plataformas, qué une cada puente y por dónde bajan las tirolinas. rampPoints calcula la rampa en espiral: un tablón cada 15°, con la pendiente justa para subirla andando (24°) y terminando exactamente a la altura de la plataforma más alta. Como es lógica pura, los tests comprueban que los árboles no se pisan, que las rampas llegan arriba y que las piedras de los atajos están a distancia de salto.

4.12 DataService · guardar sin duplicar

El problema clásico: un jugador sale de un servidor y entra en otro antes de que el primero termine de guardar. El segundo carga datos viejos, y si había un intercambio de por medio, aparecen criaturas duplicadas. La solución es un bloqueo de sesión: el perfil guardado lleva una marca con el JobId del servidor que lo tiene abierto.

sequenceDiagram participant A as Servidor A participant DS as DataStore participant B as Servidor B A->>DS: UpdateAsync: ¿bloqueado? no → Lock = A Note over A: El jugador juega en A B->>DS: UpdateAsync: ¿bloqueado? sí (A, reciente) → cancelar B-->>B: espera 4 s y reintenta A->>DS: Guardar y liberar (Lock = nil) B->>DS: UpdateAsync: libre → Lock = B ✔ 
-- Intenta abrir el perfil tomando el bloqueo. Devuelve nil si otro servidor lo tiene.
local function acquire(player: Player): (boolean, any)
	local s = store :: DataStore
	local locked = false
	local ok, raw = retry("cargar " .. player.Name, function()
		locked = false
		return s:UpdateAsync(key(player), function(old: any)
			if type(old) == "table" and type(old.Lock) == "table" then
				local lock = old.Lock
				local fresh = type(lock.Time) == "number" and now() - lock.Time < Config.Data.LockTimeoutSeconds
				if lock.JobId ~= game.JobId and fresh then
					locked = true
					return nil -- no escribir: otro servidor tiene la sesión
				end
			end
			local data = if type(old) == "table" then old.Data else nil
			return { Data = data, Lock = { JobId = game.JobId, Time = now() } }
		end)
	end)
	if not ok then
		return false, nil
	end
	if locked then
		return false, "locked"
	end
	return true, if type(raw) == "table" then raw.Data else nil
end

Devolver nil dentro de UpdateAsync cancela la escritura: así se comprueba y se toma el bloqueo en una sola operación atómica. Si el bloqueo es más antiguo que LockTimeoutSeconds ( s), se considera abandonado, por ejemplo porque el otro servidor se cayó.

local function write(player: Player, profile: Profile, release: boolean): boolean
	if useMemory then
		return true
	end
	local s = store :: DataStore
	profile.LastSeen = now()
	local written = false
	local ok = retry("guardar " .. player.Name, function()
		written = false
		return s:UpdateAsync(key(player), function(old: any)
			if type(old) == "table" and type(old.Lock) == "table" and old.Lock.JobId ~= game.JobId then
				return nil -- perdimos el bloqueo; no pisar datos de otro servidor
			end
			if not release and released[player] then
				return nil -- ya se guardó al salir; no reabrir la sesión
			end
			written = true
			return {
				Data = profile,
				Lock = if release then nil else { JobId = game.JobId, Time = now() },
			}
		end)
	end)
	return ok and written
end

Al guardar se vuelve a comprobar el bloqueo. Si otro servidor lo tiene, no se escribe, para no pisar sus datos. Al salir el jugador se guarda con release = true y se libera.

🔁 retry

Cada operación se reintenta hasta 5 veces, con esperas cada vez más largas. Los DataStores pueden fallar de forma puntual.

⏲️ Autosave

Cada s se guardan todos los perfiles, para no perder mucho si se cae el servidor.

🛑 BindToClose

Cuando Roblox cierra el servidor, se guardan todos los perfiles. Hay como mucho unos 25 s para hacerlo.

📤 markChanged

Marca el perfil como "sucio". Cada 0,25 s se envía la vista actualizada al cliente, agrupando los cambios en un solo mensaje.

	-- Fuera quien se fue, quien ya está jugando o quien no ha cargado.
	for index = #queue, 1, -1 do
		local group = queue[index]
		for k = #group.Members, 1, -1 do
			if not canQueue(group.Members[k]) then
				table.remove(group.Members, k)
			end
		end

		end

		launchAt = nil
		publish()
		return
	end

-- Teletransporte con reintentos. reserved = servidor privado nuevo (una partida).
function MatchService.teleport(players: { Player }, placeId: number, data: { [string]: any }, reserved: boolean): boolean
	if #players == 0 then
		return true
	end
	-- Guardar antes de irse: el servidor de destino lee el perfil en cuanto el jugador llega
	-- (el bloqueo se suelta al salir de aquí; DataService del destino reintenta mientras tanto).
	for _, player in players do
		task.spawn(DataService.saveNow, player)
	end
	for attempt = 1, Config.Matchmaking.TeleportRetries do
		local ok, err = pcall(function()
			local options = Instance.new("TeleportOptions")
			if reserved then
				options.ReservedServerAccessCode = (TeleportService:ReserveServer(placeId))
			end
			options:SetTeleportData(data)
			TeleportService:TeleportAsync(placeId, players, options)
		end)
		if ok then
			return true
		end
		warn(string.format("[MatchService] Teletransporte fallido (intento %d): %s", attempt, tostring(err)))
		task.wait(2 * attempt)
	end
	return false
end

Sin perder datos al cambiar de servidor. Antes de teletransportar se guarda el perfil. 		return 0
	end

	local room = HeatService.capacity(player) - s.Heat

local function setupBumpPrompt(player: Player, character: Model)
	local root = character:WaitForChild("HumanoidRootPart", 10)
	if not root then
		return
	end
	local prompt = Instance.new("ProximityPrompt")
	prompt.Name = "BumpPrompt"
	prompt.ActionText = "Empujar"
	prompt.ObjectText = "Bolsa llena"
	prompt.KeyboardKeyCode = Enum.KeyCode.F
	prompt.GamepadKeyCode = Enum.KeyCode.ButtonY
	prompt.HoldDuration = 0
	prompt.MaxActivationDistance = Config.Heat.BumpRange
	prompt.RequiresLineOfSight = false
	prompt.Enabled = false
	prompt.Parent = root

	prompt.Triggered:Connect(function(bumper)
		if bumper == player or not active then
			return
		end
		local victim = state(player)
		local now = os.clock()
		if now - victim.LastBumped < Config.Heat.BumpCooldown or victim.Heat < HeatService.capacity(player) then
			return
		end
		-- GDD v2: protección de novatos y no acosar siempre a la misma persona.
		if isProtected(player) then
			AnnouncementService.player(bumper, player.DisplayName .. " es nuevo: todavía no se le puede empujar.")
			return
		end
		local victims = bumpedPairs[bumper]
		if victims and now - (victims[player] or -math.huge) < Config.Heat.BumpSameTargetCooldown then
			AnnouncementService.player(bumper, "Ya has empujado a " .. player.DisplayName .. " hace poco.")
			return
		end
		bumpedPairs[bumper] = victims or {}
		bumpedPairs[bumper][player] = now
		local bumperRoot = rootOf(bumper)
		local victimRoot = rootOf(player)
		if not bumperRoot or not victimRoot or (bumperRoot.Position - victimRoot.Position).Magnitude > Config.Heat.BumpRange + 3 then
			return
		end
		victim.LastBumped = now
		local dropped = math.floor(victim.Heat * Config.Heat.BumpDropFraction)
		victim.Heat -= dropped
		sync(player)
		dropEmbers(victimRoot.Position, dropped)
		AnnouncementService.matchSound("Bump", victimRoot.Position)
		victimRoot.AssemblyLinearVelocity += (victimRoot.Position - bumperRoot.Position).Unit * 40 + Vector3.new(0, 20, 0)
		AnnouncementService.player(player, string.format("¡%s te ha empujado! Se te cayeron %d de Calor.", bumper.DisplayName, dropped))
	end)

	player:GetAttributeChangedSignal("BagFull"):Connect(function()
		prompt.Enabled = player:GetAttribute("BagFull") == true and active and not isProtected(player)
	end)
end

local function onStealTriggered(chase: Chase, thief: Player)
	local current = chase.Carrier
	if chase.Done or not current or thief == current or not canAct(thief) then
		return
	end
	local now = os.clock()
	if Config.Chase.TapSteal then
		-- Un toque empieza el tira y afloja; el Heartbeat lo termina o lo rompe.
		if tugs[thief] then
			return
		end
		if now < chase.ImmuneUntil then
			AnnouncementService.player(thief, "¡El portador es inmune unos segundos!")
			return
		end
		if distance(thief, current) > Config.Chase.StealRange + ChaseRules.DistanceTolerance then
			return
		end
		countAttempt(thief)
		tugs[thief] = { Chase = chase, Carrier = current, StartedAt = now }
		thief:SetAttribute("TugEndsAt", workspace:GetServerTimeNow() + ChaseRules.holdTime())
		updateTugWarning(current)
		return
	end
	-- Modo clásico: el tiempo de pulsación lo mide el servidor.
	local hold = holdStart[thief]
	holdStart[thief] = nil
	local began = if hold and hold.Chase == chase then hold.At else nil
	local check = ChaseRules.canSteal(now, began, chase.ImmuneUntil, distance(thief, current))
	if check == "immune" then
		AnnouncementService.player(thief, "¡El portador es inmune unos segundos!")
	end
	if check == "ok" then
		completeSteal(chase, thief)
	end
end
¿Por qué cuenta el tiempo el servidor? Un cliente modificado podría disparar el prompt al instante. Por eso el toque solo empieza el tira y afloja: el robo ocurre cuando el servidor ha visto pasar el tiempo real con el ladrón cerca. Con TapSteal = false vuelve el modo antiguo (mantener el botón), también medido en el servidor con PromptButtonHoldBegan.
-- Tira y afloja (robo por toque): se rompe si el portador se aleja.
for thief, tug in tugs do
	local chase = tug.Chase
	local carrier = chase.Carrier
	if chase.Done or carrier ~= tug.Carrier or not carrier or not thief.Parent then
		cancelTug(thief, nil)
		continue
	end
	local d = distance(thief, carrier)
	if d > Config.Chase.StealRange + ChaseRules.DistanceTolerance or (stunnedUntil[thief] or 0) > now then
		cancelTug(thief, "¡Se te ha escapado!")
		updateTugWarning(carrier)
		continue
	end
	if now - tug.StartedAt >= ChaseRules.holdTime() then
		local check = ChaseRules.canSteal(now, tug.StartedAt, chase.ImmuneUntil, d)
		cancelTug(thief, nil)
		updateTugWarning(carrier)
		if check == "ok" then
			completeSteal(chase, thief)
		end
	end

	if not current then
		return
	end
	local now = os.clock()
	-- Escudo de Afinidad: se rompe y el robo no ocurre.
	if (shields[current] or 0) > 0 then
		shields[current] -= 1
		current:SetAttribute("Shields", shields[current])
		chase.ImmuneUntil = now + Config.Chase.ImmunityAfterSteal
		cancelTugsOn(chase)
		updateTugWarning(current)
		AnnouncementService.match(string.format("🛡️ ¡El escudo de %s ha bloqueado a %s!", current.DisplayName, thief.DisplayName), "info")
		local root = rootOf(current)
		AnnouncementService.matchSound("ShieldBreak", if root then root.Position else nil)
		return
	end
	if ChaseService.allied(current, thief) then
		deals[current][thief] = nil
		if deals[thief] then
			deals[thief][current] = nil
		end
		DataService.addStat(thief, "PactsBroken", 1)
		AnnouncementService.match(string.format("💔 ¡%s ha traicionado a %s!", thief.DisplayName, current.DisplayName), "rare")
	else
		AnnouncementService.match(string.format("¡%s le ha robado la criatura a %s!", thief.DisplayName, current.DisplayName), "info")
	end
	local thiefRoot = rootOf(thief)
	AnnouncementService.matchSound("Steal", if thiefRoot then thiefRoot.Position else nil)
	DataService.addStat(thief, "Steals", 1)
	LeaderboardService.addSteal(thief)
	QuestService.progress(thief, "Steal", 1)
	if Config.Chase.StunSeconds > 0 then
		stunnedUntil[current] = now + Config.Chase.StunSeconds
		AnnouncementService.player(current, string.format("¡Te la han robado! Aturdido %d s", Config.Chase.StunSeconds))
	end
	setCarrier(chase, thief)
end

function ChaseService.foxGrab(index: number, foxPosition: Vector3, tugStartedAt: number): string
	local chase = chaseByIndex(index)
	local carrier = chase and chase.Carrier
	local root = carrier and rootOf(carrier)
	if not chase or chase.Done or not carrier or not root then
		return "no"
	end
	local now = os.clock()
	local check = ChaseRules.canSteal(now, tugStartedAt, chase.ImmuneUntil, (root.Position - foxPosition).Magnitude)
	if check ~= "ok" then
		return "no"
	end
	if (shields[carrier] or 0) > 0 then
		shields[carrier] -= 1
		carrier:SetAttribute("Shields", shields[carrier])
		chase.ImmuneUntil = now + Config.Chase.ImmunityAfterSteal
		AnnouncementService.match(string.format("🛡️ ¡El escudo de %s ha espantado a un zorro!", carrier.DisplayName), "info")

	AnnouncementService.match(string.format("🦊 ¡Un zorro le ha tirado la criatura al suelo a %s!", carrier.DisplayName), "threshold")
	drop(chase, root.Position)
	AnnouncementService.matchSound("Drop", root.Position)
	return "dropped"
end

-- Flecha de objetivo: un haz desde el jugador hasta lo que le toca hacer ahora.
local function currentTarget(): Vector3?
	if player:GetAttribute("InMatch") ~= true then
		return nil
	end
	local phase = RoundState.phase()
	if phase == "Incubation" then
		local heat = tonumber(player:GetAttribute("Heat")) or 0
		local capacity = tonumber(player:GetAttribute("BagCapacity")) or 100
		local offering = player:GetAttribute("Offering")
		if heat >= capacity * 0.5 or (type(offering) == "string" and offering ~= "") then
			local egg = mapChild("Egg")
			return if egg and egg:IsA("BasePart") then egg.Position else nil
		end
	elseif phase == "Chase" then
		if player:GetAttribute("IsCarrier") then
			return nil -- el portador no necesita flecha: tiene que esconderse
		end
		-- Puede haber varias criaturas: donde se vio al portador más cercano en la última
		-- señal (GDD v3: entre señales no se sabe dónde está), o una criatura suelta.
		local own = player.Character and player.Character:FindFirstChild("HumanoidRootPart")
		local from = if own and own:IsA("BasePart") then own.Position else Vector3.zero
		local best: Vector3? = nil
		local bestDistance = math.huge
		local function consider(position: Vector3)
			local d = (position - from).Magnitude
			if d < bestDistance then
				best, bestDistance = position, d
			end
		end
		for _, position in lastSeen do
			consider(position)
		end
		for _, creature in CollectionService:GetTagged("RoundCreature") do
			local body = if creature:IsA("Model") then creature.PrimaryPart else nil
			if body and body:FindFirstChild("PickupPrompt") then
				consider(body.Position)
			end
		end
		return best
	end
	return nil
end

4.24 HatchController · la eclosión en 10 segundos

El momento pensado para grabarse. En la primera versión duraba 30 s con la cámara bloqueada: demasiado tiempo mirando una ruleta sin poder hacer nada. Ahora dura s, la cámara sigue siendo tuya (puedes ir colocándote para la persecución) y el foco solo salta entre los favoritos (los 5 con más probabilidad, más los elegidos). Tres actos con proporciones fijas sobre la duración que manda el servidor:

60 % · Focosuno por criatura, se frenan
20 %revelación
-- GDD v2: 10 segundos y sin bloquear la cámara (antes 30 s mirando una ruleta). El huevo se
-- agrieta, un foco salta entre los favoritos y se para en cada elegido.
local function play(data: any)
	if running then
		return
	end
	running = true
	local duration = tonumber(data.Duration) or 10
	local order: { Candidate } = data.Order or {}
	local picks: { any } = data.Picks or {}

	overlay.Visible = true
	captureButton.Visible = false
	local mine = 0
	for _, candidate in order do
		if candidate.UserId == player.UserId then
			mine = candidate.Chance
		end
	end
	chanceLabel.Text = string.format("Tu probabilidad: %.1f %%", mine * 100)

	-- Fase 1 (20 %): el huevo tiembla. La cámara sigue siendo tuya: puedes ir colocándote.
	local eggPart = egg()
	local originalCFrame = if eggPart then eggPart.CFrame else CFrame.new()
	local crackTime = duration * 0.2
	local shakeEnd = os.clock() + crackTime
	show(if #picks > 1 then string.format("¡%d CRIATURAS!", #picks) else "¿A QUIÉN ELEGIRÁ?", "El huevo se está agrietando...", UI.Colors.Accent)
	local connection = RunService.RenderStepped:Connect(function()
		if not eggPart then
			return
		end
		local remaining = shakeEnd - os.clock()
		if remaining > 0 then
			local intensity = 0.3 + (1 - remaining / crackTime) * 0.7
			eggPart.CFrame = originalCFrame * CFrame.Angles(math.rad(math.random(-10, 10) * intensity), 0, math.rad(math.random(-10, 10) * intensity))
		end
	end)
	task.wait(crackTime)
	connection:Disconnect()
	if eggPart then
		eggPart.CFrame = originalCFrame
	end

	-- Fase 2 (60 %): un foco por criatura salta entre los favoritos y se para en su elegido.
	local candidates = shortlist(order, picks)
	local spots: { Part } = {}
	local perPick = duration * 0.6 / math.max(#picks, 1)
	for _, pick in picks do
		local spot = makeSpotlight()
		table.insert(spots, spot)
		local rarity: Rarity.RarityName = if Rarity.isValid(pick.Rarity) then pick.Rarity else "Common"
		local steps = math.max(#candidates * 2, 6)
		local chosenIndex = 1
		for index, candidate in candidates do
			if candidate.UserId == pick.UserId then
				chosenIndex = index
			end
		end
		-- Ajusta el número de pasos para acabar exactamente en el elegido.
		if #candidates > 0 then
			steps += (chosenIndex - (steps % #candidates) - 1) % #candidates + 1
		end
		for step = 1, steps do
			local candidate = candidates[((step - 1) % math.max(#candidates, 1)) + 1]
			local root = candidate and rootOf(candidate.UserId)
			if root then
				placeSpot(spot, root.Position)
				show(string.upper(candidate.Name), string.format("%.1f %%", candidate.Chance * 100), UI.Colors.Gold)
			end
			-- Intervalos crecientes: suspense al final.
			local t = step / steps
			task.wait((perPick / steps) * (0.4 + 1.2 * t * t))
		end
		local chosenRoot = rootOf(pick.UserId)
		if chosenRoot then
			placeSpot(spot, chosenRoot.Position)
		end
		local info = Rarity.Info[rarity]
		spot.Color = UI.rgb(info.Color)
		if pick.UserId == player.UserId then
			show("¡EL HUEVO TE HA ELEGIDO!", string.format("%s (%s) · ¡Corre a tu nido!", tostring(pick.CreatureName), info.DisplayName), UI.Colors.Gold)
		else
			show(string.format("¡ELIGE A %s!", string.upper(tostring(pick.Name))), string.format("%s (%s) · ¡Róbasela!", tostring(pick.CreatureName), info.DisplayName), UI.rgb(info.Color))
		end
	end

	-- Fase 3: la revelación se queda en pantalla hasta que empieza la persecución.
	captureButton.Visible = true
	task.wait(math.max(duration * 0.2 - 0.3, 0.8))
	for _, spot in spots do
		spot:Destroy()
	end
	TweenService:Create(title, TweenInfo.new(0.3), { TextTransparency = 1 }):Play()
	task.wait(0.3)
	title.TextTransparency = 0
	overlay.Visible = false
	running = false
end

Dos detalles de la ruleta:

  • Termina siempre en el elegido. Se calcula cuántos pasos dar para que el último caiga justo sobre él. Con varias criaturas hay un foco por criatura, del color de su rareza.
  • Se va frenando. Los intervalos crecen de forma cuadrática (0.4 + 1.2·t²), igual que una ruleta real, y eso crea suspense.

El temblor del huevo es solo local: el cliente mueve su copia de la pieza y el servidor nunca se entera. Al final aparece un botón de captura que usa CaptureService.

🌍 Huevo Comunitario

Todo el Calor que se deposita en cualquier servidor también llena una barra global del mes. Cada servidor acumula lo suyo y cada 30 s lo suma a una clave de MemoryStoreService (una por mes, que caduca sola). La operación es atómica: UpdateAsync lee y escribe sin que otro servidor se cuele en medio.

local function flush()
	rollMonth()
	local store = map
	if not store then
		return
	end
	local amount = pending
	pending = 0
	local key = month
	local ok, result = pcall(function(): any
		if amount > 0 then
			return store:UpdateAsync(key, function(old)
				return (tonumber(old) or 0) + amount
			end, EXPIRATION)
		end
		return store:GetAsync(key)
	end)
	if key ~= month then
		return -- cambió el mes mientras se enviaba
	end
	if ok then
		-- Lo aportado durante la espera sigue en pending: se suma a la vista local.
		total = math.max(tonumber(result) or 0, 0) + pending
	else
		pending += amount -- se reintenta en el siguiente envío
	end
	publish()
	checkFull()
end

function Economy.partyShare(amount: number, others: number): (number, number)
	if others <= 0 then
		return amount, 0

🤝 Intercambio con doble confirmación

Las estafas típicas de Roblox consisten en cambiar la oferta en el último segundo o meter prisa al otro. Trade.luau es una máquina de estados pura que lo impide:

-- Cambia la oferta de un lado. `owned` dice si ese jugador tiene la criatura y si se puede
-- intercambiar. Devuelve false si la oferta no es válida (y no cambia nada).
function Trade.setOffer(state: State, side: Side, ids: { string }, owned: (string) -> boolean): boolean
	if #ids > Config.Trade.MaxItems then
		return false
	end
	local seen = {}
	for _, id in ids do
		if type(id) ~= "string" or seen[id] or not owned(id) then
			return false
		end
		seen[id] = true
	end
	state.Offers[side] = table.clone(ids)
	state.Version += 1
	resetConfirmations(state)
	return true
end

Cualquier cambio en cualquiera de las dos ofertas quita el "Listo" de los dos. Cuando los dos están listos, hay que esperar s antes de poder confirmar. Los dos ven el valor estimado (Monedas/s) de cada oferta.

-- Paso 2. Devuelve true cuando los dos han confirmado: hay que ejecutar el intercambio.
function Trade.confirm(state: State, side: Side, now: number): boolean
	if not (state.Ready.A and state.Ready.B) or not state.ReadyAt then
		return false
	end
	if now - state.ReadyAt < Config.Trade.ConfirmDelay then
		return false
	end
	state.Confirmed[side] = true
	return state.Confirmed.A and state.Confirmed.B
end

El cambio en sí es atómico. Los dos perfiles están cargados en este servidor con su bloqueo de sesión, se modifican sin ninguna espera entre medias y se guardan enseguida. Trade.apply vuelve a comprobar que cada uno sigue teniendo lo que ofrece (por si liberó o le saquearon una criatura). Si falta algo, no cambia nada y se cancela.

4.31 Ranking semanal y salón de la fama

Junto al claro del huevo hay un cartel con dos listas: los ladrones de la semana (robos en la persecución) y el salón de la fama (nidos con más "me gusta"). Abajo aparece el campeón de la semana pasada. Para dar "me gusta" hay que ir a la entrada de un nido ajeno y pulsar G: uno por nido y semana, como mucho . Cada semana usa su propio OrderedDataStore (Steals_W2964, Likes_W2964…), así que el ranking se reinicia solo cada lunes sin borrar nada. La semana se calcula a partir de la fecha:

-- Número de semana: empieza el lunes a las 00:00 UTC (el 1/1/1970 fue jueves).
function Leaderboard.weekIndex(t: number): number
	return math.floor((math.floor(t / 86400) + 3) / 7)
end

Escribir en un DataStore en cada robo agotaría el límite de peticiones. Por eso cada servidor suma en local y, cada s, envía lo acumulado con UpdateAsync y lee el top. Lo que no se pudo enviar se reintenta en la siguiente vuelta, y mientras tanto se suma a lo leído para que el cartel no "retroceda":

-- Combina el top guardado con lo sumado en este servidor que aún no se ha enviado, y
-- devuelve los `size` primeros ordenados (empates: menor UserId primero, para que sea estable).
function Leaderboard.merge(stored: { Entry }, pending: { [number]: number }, size: number): { Entry }
	local totals: { [number]: number } = {}
	for _, entry in stored do
		totals[entry.UserId] = math.max(totals[entry.UserId] or 0, entry.Value)
	end
	for userId, delta in pending do
		totals[userId] = (totals[userId] or 0) + delta
	end
	local list: { Entry } = {}
	for userId, value in totals do
		if value > 0 then
			table.insert(list, { UserId = userId, Value = value })
		end
	end
	table.sort(list, function(a: Entry, b: Entry)
		if a.Value ~= b.Value then
			return a.Value > b.Value
		end
		return a.UserId < b.UserId
	end)
	while #list > size do
		table.remove(list)
	end
	return list
end

El simulador comprueba el equilibrio, pero no puede encontrar fallos de Roblox: un prompt que no aparece, un remoto mal validado, un modelo que se cae del mapa. Para eso hay un modo de prueba que solo existe dentro de Studio. Con Test → Clients and Servers y 4 jugadores, Player1 eres tú y el resto juegan solos. El piloto automático no es un bot aparte: mueve el personaje con Humanoid:MoveTo y pulsa los mismos ProximityPrompts que una persona con InputHoldBegin/InputHoldEnd. El servidor mide el tiempo de pulsación igual que siempre, así que un robo del piloto pasa por la misma validación que uno real.

-- Mantiene pulsado un prompt real durante unos segundos (como una persona con la tecla E).
local function hold(prompt: ProximityPrompt, seconds: number)
	if holding == prompt then
		return
	end
	if holding then
		holding:InputHoldEnd()
	end
	holding = prompt
	holdUntil = os.clock() + seconds
	prompt:InputHoldBegin()
end

Cada 0,25 s decide qué hacer según la fase. Si lleva 2,5 s sin moverse (un árbol, una pared), salta y descarta ese objetivo durante 8 s.

local function chase(root: BasePart)
	if player:GetAttribute("IsCarrier") then
		release()
		-- ¿Hay ladrones cerca?
		local nearest = math.huge
		local threat: Vector3? = nil
		for _, other in Players:GetPlayers() do
			local r = if other ~= player and other:GetAttribute("InMatch") then rootOf(other) else nil
			if r and (r.Position - root.Position).Magnitude < nearest then
				nearest = (r.Position - root.Position).Magnitude
				threat = r.Position
			end
		end
		if nearest < 15 then
			Remotes.event("RequestSprint"):FireServer()
		end
		-- Huir por el parkour: cambiar de escondite si se acercan o tras un rato.
		if not hideSpot or os.clock() > hideUntil or (nearest < 18 and math.random() < 0.15) then
			hideSpot = pickHideSpot(root, threat)
			hideUntil = os.clock() + math.random(10, 18)
		end
		moveTo(hideSpot :: Vector3)
		return
	end
	hideSpot = nil

	-- Puede haber varias criaturas: una suelta cerca es lo primero.
	for _, creature in CollectionService:GetTagged("RoundCreature") do
		local body = if creature:IsA("Model") then creature.PrimaryPart else nil
		local pickup = body and body:FindFirstChild("PickupPrompt")
		if body and pickup and pickup:IsA("ProximityPrompt") and flat(body.Position, root.Position) < 60 then
			moveTo(body.Position)
			if (body.Position - root.Position).Magnitude < 8 then
				hold(pickup, pickup.HoldDuration + 0.2)
			end
			return
		end
	end
	-- Un portador a la vista (cerca), o a donde se le vio en la última señal.
	local carrierRoot: BasePart? = nil
	local best = math.huge
	for _, id in string.split(tostring(RoundState.get("Carriers") or ""), ",") do
		local carrier = Players:GetPlayerByUserId(tonumber(id) or 0)
		local r = if carrier and carrier ~= player then rootOf(carrier) else nil
		local d = if r then (r.Position - root.Position).Magnitude else math.huge
		if r and d < best and (d < 40 or RoundState.get("Revealed")) then
			carrierRoot, best = r, d
		end
	end
	if not carrierRoot then
		local seen = lastSeen()
		local closest: Vector3? = nil
		local closestDistance = math.huge
		for _, p in seen do
			local d = (p - root.Position).Magnitude
			if d < closestDistance then
				closest, closestDistance = p, d
			end
		end
		if closest then
			moveTo(closest)
		end
		return
	end
	moveTo(carrierRoot.Position)
	local distance = (carrierRoot.Position - root.Position).Magnitude
	local prompt = carrierRoot:FindFirstChild("StealPrompt")
	-- Con robo por toque basta un toque; luego hay que quedarse cerca (el servidor cuenta).
	if prompt and prompt:IsA("ProximityPrompt") and distance < Config.Chase.StealRange - 1 and not player:GetAttribute("TugEndsAt") then
		hold(prompt, prompt.HoldDuration + 0.2)
	elseif holding and distance > Config.Chase.StealRange then
		release()
	end
end
