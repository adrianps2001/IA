Parte 1 · 10 %

Lo que debes saber como creador de Roblox

La plataforma, cómo se divide el trabajo entre cliente y servidor, cómo se guardan datos, cómo se gana dinero y qué reglas hay que respetar para publicar sin problemas.

1.1 Cómo funciona Roblox por dentro

Un juego de Roblox (oficialmente una experiencia) es un árbol de objetos llamado DataModel, al que el código accede como game. Cada objeto es una Instance: una pieza (Part), una carpeta (Folder), un script, un sonido… Las ramas principales del árbol son servicios, y cada uno tiene una función:

ReplicatedStorageCosas compartidas que no están en el mundoServidor y clientesShared (módulos comunes), Remotes, RoundState
ServerScriptServiceScripts del servidorSolo el servidorServer y sus 10 servicios

🖥️ Script

Se ejecuta en el servidor. Aquí vive la verdad del juego: dinero, robos, quién gana.

📱 LocalScript

Se ejecuta en el dispositivo de cada jugador: interfaz, cámara, efectos y controles.

🧩 ModuleScript

Código reutilizable que no se ejecuta solo: otros scripts lo cargan con require. Casi todo este proyecto son módulos.

1.2 Cliente y servidor: la regla de oro

Cada partida corre en un servidor de Roblox al que se conectan hasta N jugadores (aquí, ). Lo que cambia el servidor se replica a los clientes. Lo que cambia un cliente no llega a los demás, salvo la física de su propio personaje. Para comunicarse se usan RemoteEvents (mensajes) y RemoteFunctions (preguntas con respuesta).

flowchart LR subgraph S[Servidor · autoritativo] D[(DataStore)] SV[Servicios: rondas, robos, dinero] end subgraph C1[Cliente de Ana] UI1[HUD, botones, cámara] end subgraph C2[Cliente de Leo] UI2[HUD, botones, cámara] end UI1 -- "RemoteEvent: quiero esprintar" --> SV SV -- "Atributos y RemoteEvents: estado" --> UI1 SV -- "réplica automática" --> UI2 SV <--> D
Nunca te fíes del cliente. Hay jugadores que modifican su cliente para hacer trampas: pueden enviar cualquier mensaje, a cualquier ritmo y con cualquier dato. Por eso en este proyecto el cliente solo pide cosas ("quiero robar", "quiero mejorar la bolsa"). El servidor comprueba la distancia, el tiempo, las Monedas y la fase antes de hacer nada. Un ejemplo: el robo exige mantener la tecla 1,5 s, y es el servidor quien mide ese tiempo.

Además, con StreamingEnabled (activado en este proyecto) el cliente solo carga las partes del mundo que tiene cerca. Por eso el código del cliente usa FindFirstChild y comprueba si algo existe antes de usarlo.

1.3 Guardar datos

💾 DataStoreService

Almacén permanente de clave-valor. Aquí, una clave por jugador (player_<UserId>). Tiene límites de peticiones por minuto y de tamaño por clave, así que se guarda en lotes (autosave cada s).

🔒 UpdateAsync

Lee y escribe de forma atómica, y permite cancelar la escritura. Es la base del bloqueo de sesión que evita duplicar criaturas al saltar de servidor.

📡 MessagingService

Mensajes entre servidores del mismo juego. Aquí se usa para el aviso global de las criaturas Míticas y Secretas.

⚡ MemoryStoreService

Datos temporales y muy rápidos compartidos entre servidores (colas, rankings). Está previsto para el ranking semanal y el Huevo Comunitario.

En Studio los DataStores solo funcionan si activas Game Settings → Security → Enable Studio Access to API Services. Si no, DataService lo detecta y juega en memoria.

1.5 Cómo se gana dinero en Roblox

Todo se cobra en Robux. De las ventas de pases y productos dentro del juego, el creador recibe aproximadamente el 70 % y Roblox se queda el resto. Los Robux ganados se pueden cambiar por dinero real con DevEx (Developer Exchange), que pide unos requisitos mínimos. 1.6 Reglas y políticas que afectan al diseño

🎲 Objetos aleatorios de pago

Si se paga por algo aleatorio (un huevo), hay que mostrar las probabilidades antes de comprar. La tienda las calcula con Rarity.chances. Además, en algunos países están restringidos: MonetizationService pregunta a PolicyService y la tienda los oculta a quien no pueda comprarlos.

🧒 Público joven

Todo el texto que escriban los jugadores debe pasar por el filtro de Roblox (el chat oficial ya lo hace). No se pueden pedir datos personales. El GDD evita la violencia: robar es tocar y mantener, nunca pegar.

🏷️ Etiqueta de madurez

Antes de publicar se rellena el cuestionario de contenido del Creator Hub, que asigna la etiqueta de edad que verán los jugadores.

🚫 Prohibido

Miniaturas engañosas o promesas de "Robux gratis", mandar a pagar fuera de Roblox y copiar personajes o marcas de otros (ya hay demandas por clones).

⚖️ Monetización ética (GDD 9.6)

Ninguna compra garantiza ser elegido ni ganar la persecución. El Escudo está limitado a 1 por ronda y las Secretas no se pueden forzar con la Ofrenda Dorada.

📜 Normas de la comunidad

Las Community Standards y los Terms of Use se aplican a todo: nombres, imágenes, textos y anuncios del juego.

1.7 Descubrimiento y métricas

Roblox recomienda juegos según cómo se comportan sus jugadores: si vuelven al día siguiente, cuánto juegan y si les gusta. Según el GDD, en 2026 pesa sobre todo la retención a largo plazo. Por eso este diseño tiene un nido que produce aunque no estés, misiones diarias y racha.

2.3 Cómo arranca el juego

Todos los servicios siguen el mismo contrato: init() prepara lo suyo sin esperar a nada y start() conecta eventos y lanza bucles. Primero se llama a init() en todos y después a start() en todos. Así, cuando un servicio arranca, los demás ya están preparados.

--!strict
-- Arranque del servidor: init() de todos los servicios (sin esperas) y luego start().

local services = {
	require(script.Services.DataService),
	require(script.Services.AnnouncementService),
	require(script.Services.MonetizationService),
	require(script.Services.MapService),
	require(script.Services.QuestService),
	require(script.Services.NestService),
	require(script.Services.EggService),
	require(script.Services.HeatService),
	require(script.Services.ChaseService),
	require(script.Services.RoundService),
	require(script.Services.DebugService), -- solo responde en Studio
}

for _, service in services do
	service.init()
end

for _, service in services do
	service.start()
end

2.4 Quién usa a quién

Las flechas indican "usa a". No hay ciclos: un módulo nunca depende, ni directa ni indirectamente, de otro que dependa de él. Si hiciera falta, se usa un callback, como QuestService.onStreakReward, que lo rellena NestService.

2.5 Cómo viaja la información

🏷️ Atributos

Pequeños valores colgados de un objeto que se replican solos. El servidor escribe player:SetAttribute("Heat", 35) y el HUD escucha el cambio. Se usan para la bolsa, las Monedas, el portador y el estado de la ronda.

📨 RemoteEvent

Mensajes puntuales. Del servidor al cliente: HatchSequence, Notify. Del cliente al servidor: RequestSprint, RequestBreed.

❓ RemoteFunction

Pregunta con respuesta. Solo GetProfile, que va del cliente al servidor y es seguro. Al revés, del servidor al cliente, sería peligroso: un cliente podría no responder nunca y dejar al servidor esperando.

👆 ProximityPrompt

El botón de "mantén E" que aparece al acercarte a algo. Roblox comprueba la distancia, y este proyecto además valida el tiempo de pulsación en el servidor.

Luau para quien ya sabe programar

Luau es el dialecto de Lua de Roblox: Lua 5.1 más tipos opcionales, operadores compuestos, interpolación de texto y una librería de tareas. Aquí tienes lo esencial, comparado con JavaScript.

3.1 Variables, tipos y operadores

JavaScript
let vida = 100;
const nombre = "Ana";
let nada = null;
if (vida !== 0 && !muerto) {}
const texto = "Hola " + nombre;
const n = lista.length;
vida += 5;
const media = 7 / 2;   // 3.5
const entera = Math.floor(7 / 2);
Luau
local vida = 100
local nombre = "Ana"
local nada = nil
if vida ~= 0 and not muerto then end
local texto = "Hola " .. nombre  -- o `Hola {nombre}`
local n = #lista
vida += 5
local media = 7 / 2   -- 3.5
local entera = 7 // 2 -- 3
  • Siempre local. Sin local la variable es global, más lenta y propensa a errores.
  • Distinto es ~=, no !=. Los operadores lógicos son palabras: and, or, not.
  • Solo nil y false son falsos. El 0 y el "" son verdaderos.
  • Un único tipo de número (coma flotante de 64 bits). .. concatena texto y # da la longitud.
  • Comentarios con --, y de varias líneas con --[[ ... ]].

3.2 Tablas: el único contenedor

La tabla hace de array, de diccionario, de objeto y de módulo a la vez.

JavaScript
const lista = ["a", "b"];
lista[0];          // "a"
lista.push("c");
const perfil = { coins: 0, dust: 5 };
perfil.coins = 10;
for (const x of lista) {}
for (const [k, v] of Object.entries(perfil)) {}
delete perfil.dust;
Luau
local lista = { "a", "b" }
lista[1]           -- "a"  ¡empieza en 1!
table.insert(lista, "c")
local perfil = { Coins = 0, Dust = 5 }
perfil.Coins = 10
for i, x in lista do end
for k, v in perfil do end
perfil.Dust = nil

Funciones útiles: table.insert, table.remove, table.find (busca un valor en un array), table.clone, table.clear y table.sort(t, function(a, b) return a < b end).

3.3 Control de flujo

JavaScript
if (x > 5) { a(); }
else if (x > 2) { b(); }
else { c(); }
const t = ok ? "sí" : "no";
for (let i = 1; i <= 10; i++) {}
for (let i = 10; i >= 2; i--) {}
while (vivo) { if (x) continue; }
Luau
if x > 5 then a()
elseif x > 2 then b()
else c() end
local t = if ok then "sí" else "no"
for i = 1, 10 do end        -- incluye el 10
for i = 10, 2, -1 do end
while vivo do if x then continue end end

También existe repeat ... until cond. Los bloques se cierran siempre con end. Es habitual escribir valor or "por defecto" para dar un valor por defecto. Ojo: si el primer valor es false, también se usa el de por defecto.

3.4 Funciones

JavaScript
function suma(a, b = 0) { return a + b; }
const doble = (x) => x * 2;
function dividir(a, b) { return [a / b, a % b]; }
const [c, r] = dividir(7, 2);
jugador.saltar();
Luau
local function suma(a, b)
    return a + (b or 0)
end
local doble = function(x) return x * 2 end
local function dividir(a, b) return a / b, a % b end
local c, r = dividir(7, 2)   -- varios retornos
jugador:Saltar()   -- ":" pasa jugador como self
  • Varios valores de retorno sin crear un array: Election.pick devuelve el elegido y las probabilidades.
  • Dos puntos (:) llama a un método pasando el objeto como primer argumento: part:Destroy() equivale a part.Destroy(part).
  • Clausuras: una función interior recuerda las variables locales de la función que la contiene. spawnSource lo usa para que cada brasa recuerde si ya la han cogido.

3.5 Módulos

Un ModuleScript devuelve un valor, normalmente una tabla con funciones. Ese valor se calcula una sola vez y se comparte con todos los que hacen require. Por eso un módulo sirve como "servicio" con estado propio.

JavaScript (ES modules)
// economy.js
export function cost(level) { ... }
// otro archivo
import { cost } from "./economy.js";
Luau
-- Economy.luau
local Economy = {}
function Economy.cost(level) ... end
return Economy
-- otro archivo
local Economy = require(Shared.Economy)   -- por instancia
local Rarity = require("./Rarity")        -- por ruta

En este proyecto, los módulos de lógica pura se cargan por ruta (require("./Rarity")), que funciona igual en Roblox y en el luau de la terminal. Por eso se pueden probar fuera de Studio. El resto usa la ruta por instancia (script.Parent.DataService).

4.2 Rarity.luau · las seis rarezas

Cada rareza tiene un nivel (1–6), un peso sobre 1.000.000, su producción base y su color. Los colores son el lenguaje visual del GDD: gris, verde, azul, morado, naranja y rojo. La tirada funciona así: se suman los pesos permitidos, se elige un punto al azar en ese total y se recorre la lista restando pesos hasta que el punto "cae" dentro de una rareza.

-- Elige una rareza. La suerte multiplica el peso de todo lo que no es Común;
-- minRarity y maxRarity recortan el rango posible.
function Rarity.roll(rng: () -> number, luck: number?, minRarity: RarityName?, maxRarity: RarityName?): RarityName
	local luckValue = math.max(luck or 1, 0)
	local minTier = if minRarity then Rarity.tier(minRarity) else 1
	local maxTier = if maxRarity then Rarity.tier(maxRarity) else #Rarity.Order

	local total = 0
	local weights = {}
	for _, name in Rarity.Order do
		local info = Rarity.Info[name]
		local weight = 0
		if info.Tier >= minTier and info.Tier <= maxTier then
			weight = info.Weight * (if info.Tier > 1 then luckValue else 1)
		end
		weights[name] = weight
		total += weight
	end

	if total <= 0 then
		return Rarity.fromTier(minTier)
	end

	local pick = rng() * total
	for _, name in Rarity.Order do
		pick -= weights[name]
		if pick < 0 then
			return name
		end
	end
	return Rarity.fromTier(maxTier)
end

La suerte multiplica el peso de todo lo que no es Común, así que aumenta las probabilidades de todas las rarezas a la vez. minRarity y maxRarity recortan el rango; así es como los umbrales de la barra garantizan, por ejemplo, "mínimo Épica".

4.3 Genes.luau · 60 piezas, miles de criaturas

Cada criatura tiene cinco ranuras: Cuerpo, Cabeza, Patrón, Aura y Mutación. Cada ranura tiene 12 genes de distintas rarezas. Una criatura se guarda solo como cinco identificadores ("body_crystal", "head_beak"…), lo que ahorra memoria y espacio en el DataStore. Su rareza es la de su gen más raro.

demo Catálogo de genes

Para generar una criatura de rareza exacta R, rollSet elige una ranura al azar para el gen firma, que tiene exactamente esa rareza. El resto de ranuras se tiran con rareza igual o menor. Así la criatura sale con la rareza pedida y el reparto de genes sigue siendo variado.

-- Genera los genes de una criatura de rareza exacta `rarity`: una ranura recibe un gen
-- de esa rareza (el "gen firma") y el resto se tira con rareza igual o menor.
function Genes.rollSet(rng: () -> number, rarity: RarityName, biases: Biases?): GeneSet
	local tier = Rarity.tier(rarity)
	local signatureSlots: { Slot } = {}
	for _, slot in Genes.Slots do
		if #genesOfTier(slot, tier) > 0 then
			table.insert(signatureSlots, slot)
		end
	end

	local signatureSlot = signatureSlots[math.floor(rng() * #signatureSlots) + 1] or signatureSlots[1]
	local result = {}
	for _, slot in Genes.Slots do
		if slot == signatureSlot then
			local biasId = biases and biases[slot]
			local biased = biasId and Genes.ById[biasId]
			if biased and biased.Slot == slot and biased.Rarity == rarity and rng() < Genes.BiasChance then
				result[slot] = biased.Id
			else
				result[slot] = pickFrom(genesOfTier(slot, tier), rng).Id
			end
		else
			result[slot] = Genes.rollSlot(slot, rng, rarity, biases and biases[slot])
		end
	end
	return result :: any
end
-- Gen aleatorio de una ranura con rareza como mucho maxRarity.
function Genes.rollSlot(slot: Slot, rng: () -> number, maxRarity: RarityName, biasGeneId: string?): string
	local maxTier = Rarity.tier(maxRarity)
	if biasGeneId then
		local biased = Genes.ById[biasGeneId]
		if biased and biased.Slot == slot and Rarity.tier(biased.Rarity) <= maxTier and rng() < Genes.BiasChance then
			return biased.Id
		end
	end

	local tier = Rarity.tier(Rarity.roll(rng, 1, nil, maxRarity))
	while tier >= 1 do
		local candidates = genesOfTier(slot, tier)
		if #candidates > 0 then
			return pickFrom(candidates, rng).Id
		end
		tier -= 1
	end
	return Genes.BySlot[slot][1].Id
end

Ofrendas. Los objetos del mapa favorecen un gen concreto: si su rareza cabe en la tirada, hay un 50 % de probabilidad (Genes.BiasChance) de que salga ese gen. Así los veteranos pueden "dirigir" la criatura sin garantizarla.

-- Cría: cada ranura hereda de uno de los padres; con mutationChance se vuelve a tirar
-- con rareza máxima un nivel por encima del mejor padre (GDD 5.7).
function Genes.inherit(a: GeneSet, b: GeneSet, rng: () -> number, mutationChance: number): GeneSet
	local parentRarity = Rarity.max(Genes.rarityOf(a), Genes.rarityOf(b))
	local mutationCap = Rarity.fromTier(math.min(Rarity.tier(parentRarity) + 1, Rarity.tier("Mythic")))
	local child = {}
	for _, slot in Genes.Slots do
		if rng() < mutationChance then
			child[slot] = Genes.rollSlot(slot, rng, mutationCap)
		else
			child[slot] = if rng() < 0.5 then (a :: any)[slot] else (b :: any)[slot]
		end
	end
	return child :: any
end

4.4 Creature.luau · nombre, rareza y producción

Una criatura es una tabla con Id, Genes, Rarity, Origin (de dónde salió) y Born (cuándo nació). El nombre se forma con el cuerpo, más el patrón y la mutación si no son los básicos: "Cristalino Moteado Gigante".

-- Monedas por segundo sin multiplicadores del jugador.
function Creature.baseIncome(creature: Creature): number
	local bonusTiers = 0
	for _, slot in Genes.Slots do
		local gene = Genes.get((creature.Genes :: any)[slot])
		if gene then
			bonusTiers += Rarity.tier(gene.Rarity) - 1
		end
	end

La producción es la base de su rareza más un 5 % por cada nivel de rareza de sus genes por encima de Común. Dos criaturas de la misma rareza no producen igual, y esto premia tener genes buenos en todas las ranuras.

4.5 Election.luau · a quién elige el huevo

La regla del GDD: probabilidad = tu Afinidad / Afinidad total, pero nadie baja del 2 %. Así siempre puede salir el clip de "no puse nada y me eligió". Para que todo sume 100 %, el algoritmo funciona en varias pasadas:

  1. Reparte la probabilidad en proporción a la Afinidad.
  2. A quien le toque menos del mínimo, se le fija exactamente el mínimo.
  3. Lo que queda se reparte otra vez entre los que no están fijados, en proporción a su Afinidad.
  4. Repite hasta que nadie quede por debajo.
function Election.chances(entries: { Entry }, minChance: number): { [string]: number }
	local result: { [string]: number } = {}
	local count = #entries
	if count == 0 then
		return result
	end

	local function minOf(entry: Entry): number
		return entry.Min or minChance
	end

	-- Si los mínimos no caben, se reparte en proporción a ellos.
	local totalMin = 0
	for _, entry in entries do
		totalMin += minOf(entry)
	end
	if totalMin >= 1 then
		for _, entry in entries do
			result[entry.Key] = if totalMin > 0 then minOf(entry) / totalMin else 1 / count
		end
		return result
	end

	local pinned: { [string]: boolean } = {}
	while true do
		local freeMass = 1
		local freeAffinity = 0
		local freeCount = 0
		for _, entry in entries do
			if pinned[entry.Key] then
				freeMass -= minOf(entry)
			else
				freeAffinity += math.max(entry.Affinity, 0)
				freeCount += 1
			end
		end

		local changed = false
		for _, entry in entries do
			if not pinned[entry.Key] then
				local share = if freeAffinity > 0
					then freeMass * math.max(entry.Affinity, 0) / freeAffinity
					else freeMass / freeCount
				if share < minOf(entry) then
					pinned[entry.Key] = true
					changed = true
				else
					result[entry.Key] = share
				end
			end
		end

		if not changed then
			break
		end
	end

	for key in pinned do
		for _, entry in entries do
			if entry.Key == key then
				result[key] = minOf(entry)
			end
		end
	end
	return result
end

Si los mínimos no caben (más de 50 jugadores con el 2 %), la probabilidad se reparte en proporción a ellos. Si nadie ha depositado nada, todos reciben lo mismo.

4.7 Quests.luau · misiones diarias y racha

Todos los jugadores tienen las mismas 3 misiones cada día, sin guardar nada en ningún servidor. El truco es usar el número de día (días UTC desde 1970) como semilla de un generador pseudoaleatorio, que baraja la lista de misiones siempre igual para ese día.

-- Generador congruencial simple: misma selección para un día dado.
local function seededOrder(day: number, count: number): { number }
	local order = {}
	for i = 1, count do
		order[i] = i
	end
	local state = (day * 1103515245 + 12345) % 2147483648
	for i = count, 2, -1 do
		state = (state * 1103515245 + 12345) % 2147483648
		local j = (state % i) + 1
		order[i], order[j] = order[j], order[i]
	end
	return order
end

La racha: si entras el día siguiente a tu última sesión, sube 1; si te saltas un día, vuelve a 1. Al llegar a 7 se reinicia y devuelve true, y QuestService entrega un huevo especial.

-- Renueva misiones si cambió el día y actualiza la racha. Devuelve true si la racha
-- acaba de completarse (día 7), para entregar el huevo especial.
function Quests.rollover(state: QuestState, today: number): boolean
	if state.Day ~= today then
		state.Day = today
		state.List = Quests.forDay(today)
	end
	if state.StreakDay == today then
		return false
	end
	if state.StreakDay == today - 1 then
		state.Streak += 1
	else
		state.Streak = 1
	end
	state.StreakDay = today
	if state.Streak >= Config.Quests.StreakDays then
		state.Streak = 0
		return true
	end
	return false
end
-- Suma progreso. Devuelve cuántas misiones se completaron con este avance.
function Quests.progress(state: QuestState, kind: QuestKind, amount: number): number
	local completed = 0
	for _, quest in state.List do
		if quest.Kind == kind and not quest.Claimed then
			local before = quest.Progress
			quest.Progress = math.min(quest.Goal, quest.Progress + amount)
			if before < quest.Goal and quest.Progress >= quest.Goal then
				quest.Claimed = true
				completed += 1
			end
		end
	end
	return completed
end

Parte de un perfil por defecto y copia solo lo que es válido de lo guardado: números que sean números, criaturas con genes que existan, misiones bien formadas… Además, la rareza se recalcula siempre desde los genes. Así, si un día cambias la rareza de un gen, todas las criaturas guardadas se actualizan solas, y un dato corrupto nunca rompe el juego.

-- Rellena campos que falten y descarta datos corruptos sin perder lo válido.
function PlayerData.reconcile(raw: any, now: number): Profile
	local profile = PlayerData.default(now)
	if type(raw) ~= "table" then
		return profile
	end

	profile.Coins = math.max(number(raw.Coins, 0), 0)
	profile.Dust = math.max(number(raw.Dust, 0), 0)
	profile.Generation = math.max(math.floor(number(raw.Generation, 0)), 0)
	profile.LastSeen = number(raw.LastSeen, now)

	if type(raw.Upgrades) == "table" then
		for name in profile.Upgrades do
			profile.Upgrades[name] = math.max(math.floor(number(raw.Upgrades[name], 0)), 0)
		end
	end

	if type(raw.Stats) == "table" then
		for _, name in PlayerData.StatNames do
			profile.Stats[name] = math.max(number(raw.Stats[name], 0), 0)
		end
	end

	if type(raw.Creatures) == "table" then
		for _, creature in raw.Creatures do
			if Creature.isValid(creature) then
				-- La rareza siempre se recalcula a partir de los genes.
				creature.Rarity = Genes.rarityOf(creature.Genes)
				table.insert(profile.Creatures, creature)
			end
		end
	end

	if type(raw.Incubator) == "table" then
		for _, egg in raw.Incubator do
			if
				type(egg) == "table"
				and type(egg.Id) == "string"
				and type(egg.Kind) == "string"
				and Rarity.isValid(egg.MinRarity)
				and Rarity.isValid(egg.MaxRarity)
				and (egg.Genes == nil or Genes.isValidSet(egg.Genes))
			then
				egg.ReadyAt = number(egg.ReadyAt, now)
				table.insert(profile.Incubator, egg)
			end
		end
	end

	local q = raw.Quests
	if type(q) == "table" and type(q.List) == "table" then
		profile.Quests.Day = math.floor(number(q.Day, profile.Quests.Day))
		profile.Quests.StreakDay = math.floor(number(q.StreakDay, -1))
		profile.Quests.Streak = math.floor(number(q.Streak, 0))
		local list = {}
		for _, quest in q.List do
			if type(quest) == "table" and type(quest.Kind) == "string" then
				table.insert(list, {
					Kind = quest.Kind,
					Goal = math.max(number(quest.Goal, 1), 1),
					Progress = math.max(number(quest.Progress, 0), 0),
					Claimed = quest.Claimed == true,
				})
			end
		end
		if #list > 0 then
			profile.Quests.List = list
		end
	end

	if type(raw.Receipts) == "table" then
		for _, receipt in raw.Receipts do
			if type(receipt) == "string" then
				table.insert(profile.Receipts, receipt)
			end
		end
	end

	if type(raw.LastBreed) == "table" and type(raw.LastBreed[1]) == "string" and type(raw.LastBreed[2]) == "string" then
		profile.LastBreed = { raw.LastBreed[1], raw.LastBreed[2] }
	end

	if type(raw.Funnel) == "table" then
		for key, value in raw.Funnel do
			if type(key) == "string" and value == true then
				profile.Funnel[key] = true
			end
		end
	end

	if type(raw.Decorations) == "table" then
		for _, id in raw.Decorations do
			if type(id) == "string" and not table.find(profile.Decorations, id) then
				table.insert(profile.Decorations, id)
			end
		end
	end

	return profile
end

-- ¿Es válido un robo? holdStartedAt es cuándo empezó a mantener el botón (medido por el
-- servidor), immuneUntil hasta cuándo es inmune el portador y distance la separación actual.
function ChaseRules.canSteal(
	now: number,
	holdStartedAt: number?,
	immuneUntil: number,
	distance: number,
	carrierAtHome: boolean?
): StealCheck
	if not holdStartedAt then
		return "noHold"
	end
	if now - holdStartedAt < ChaseRules.holdTime(carrierAtHome == true) - ChaseRules.HoldTolerance then
		return "tooShort"
	end
	if now < immuneUntil then
		return "immune"
	end
	if distance > Config.Chase.StealRange + ChaseRules.DistanceTolerance then
		return "tooFar"
	end
	return "ok"
end

-- chosenKey es a quien eligió el huevo: si no acaba ganando, recibe un premio de consolación
-- especial (ser elegido siempre tiene que sentirse bien, aunque te la roben).
function Rewards.compute(participants: { Participant }, winnerKey: string?, partnerKeys: { string }, chosenKey: string?): { [string]: Reward }
	local result: { [string]: Reward } = {}
	local winnerDust = 0
	for _, p in participants do
		if p.Key == winnerKey then
			winnerDust = Config.Consolation.WinnerBonusDust + Economy.consolationDust(p.Affinity, p.StealAttempts)
		end
	end

	for _, p in participants do
		local reward: Reward = { Dust = 0, Creature = false, Copy = false, ChosenEgg = false }
		if p.Key == winnerKey then
			reward.Dust = winnerDust
			reward.Creature = true
		else
			reward.Dust = Economy.consolationDust(p.Affinity, p.StealAttempts)
			if winnerKey and table.find(partnerKeys, p.Key) then
				reward.Dust += math.floor(winnerDust * Config.Deal.DustShare)
				reward.Copy = true
			end
			if p.Key == chosenKey then
				reward.Dust += Config.Consolation.ChosenBonusDust
				reward.ChosenEgg = Config.Consolation.ChosenEgg
			end
		end
		result[p.Key] = reward
	end
	return result
end

-- ¿Está el punto dentro de la parcela del nido? (cuadrado girado hacia el huevo)
function MapLayout.insideNest(index: number, point: Point): boolean
	local center = MapLayout.nestCenter(index)
	local angle = MapLayout.nestAngle(index)
	local dx, dz = point.X - center.X, point.Z - center.Z
	-- Ejes locales: radial (hacia fuera) y tangencial.
	local radial = dx * math.cos(angle) + dz * math.sin(angle)
	local tangential = -dx * math.sin(angle) + dz * math.cos(angle)
	local half = MapLayout.NestSize / 2
	return math.abs(radial) <= half and math.abs(tangential) <= half
end

4.10 CreatureModel.luau · de genes a 3D

Convierte los 5 genes en un modelo 3D usando solo piezas primitivas (esferas y bloques), en línea con el GDD: "criaturas modulares, mucho resultado con poco coste de arte" y buen rendimiento en móvil.

🫧 Cuerpo

Una esfera con la forma (BODY_SHAPES), el color y el material del gen. Cristal → vidrio, lava → neón.

👀 Cabeza

Una esfera con ojos (uno solo si es Cíclope) y un "rasgo" con el color del gen: pico, halo, cuernito…

🔵 Patrón

De 4 a 9 manchas del color del gen. Brillan si el gen es Legendario o mejor.

✨ Aura

Un ParticleEmitter del color del aura; emite más cuanto más raro es el gen.

🧬 Mutación

Gigante y Diminuto cambian la escala, Fantasma es transparente, Dorado refleja la luz y Arcoíris lo anima el cliente.

🏷️ Etiqueta

Un BillboardGui con el nombre y la rareza en su color, más una luz desde Épica.

-- Devuelve un modelo anclado con PrimaryPart "Body". scale permite miniaturas.
function CreatureModel.build(creature: Creature.Creature, scale: number?): Model
	local s = scale or 1
	local genes = creature.Genes
	local body = Genes.get(genes.Body)
	local head = Genes.get(genes.Head)
	local pattern = Genes.get(genes.Pattern)
	local aura = Genes.get(genes.Aura)
	local mutation = genes.Mutation

	local sizeMultiplier = if mutation == "mut_big" then 1.6 elseif mutation == "mut_small" then 0.6 else 1
	s *= sizeMultiplier

	local model = Instance.new("Model")
	model.Name = Creature.name(creature)

	local bodyColor = if body then rgb(body.Color) else Color3.new(1, 1, 1)
	if mutation == "mut_golden" then
		bodyColor = Color3.fromRGB(255, 200, 40)
	elseif mutation == "mut_inverted" then
		bodyColor = Color3.new(1 - bodyColor.R, 1 - bodyColor.G, 1 - bodyColor.B)
	end

	-- Una pieza Ball siempre es una esfera perfecta; para las formas alargadas se usa un
	-- bloque con malla esférica, que se estira con el tamaño (igual que el huevo gigante).
	local bodyPart = part("Body", Enum.PartType.Block, (BODY_SHAPES[genes.Body] or Vector3.new(3, 3, 3)) * s, bodyColor, model)
	local bodyMesh = Instance.new("SpecialMesh")
	bodyMesh.MeshType = Enum.MeshType.Sphere
	bodyMesh.Parent = bodyPart
	bodyPart.Material = BODY_MATERIALS[genes.Body] or Enum.Material.SmoothPlastic
	model.PrimaryPart = bodyPart

	local headSize = 2 * s
	local headPart = part("Head", Enum.PartType.Ball, Vector3.new(headSize, headSize, headSize), bodyColor, model)
	headPart.CFrame = bodyPart.CFrame * CFrame.new(0, bodyPart.Size.Y * 0.45, -bodyPart.Size.Z * 0.35)
	headPart.Material = bodyPart.Material

	-- Ojos
	for _, side in { -1, 1 } do
		local eye = part("Eye", Enum.PartType.Ball, Vector3.new(0.45, 0.45, 0.45) * s, Color3.new(0.05, 0.05, 0.05), model)
		eye.CFrame = headPart.CFrame * CFrame.new(side * 0.45 * s, 0.2 * s, -headSize * 0.45)
		if genes.Head == "head_cyclops" and side == 1 then
			eye:Destroy()
		end
	end

	-- Rasgo de la cabeza: una pieza con el color del gen.
	if head then
		local crest = part("Crest", Enum.PartType.Block, Vector3.new(0.6, 0.6, 0.9) * s, rgb(head.Color), model)
		if genes.Head == "head_beak" then
			crest.CFrame = headPart.CFrame * CFrame.new(0, -0.1 * s, -headSize * 0.6)
		elseif genes.Head == "head_halo" then
			crest.Shape = Enum.PartType.Cylinder
			crest.Size = Vector3.new(0.15, 2.2, 2.2) * s
			crest.Material = Enum.Material.Neon
			crest.CFrame = headPart.CFrame * CFrame.new(0, headSize * 0.8, 0) * CFrame.Angles(0, 0, math.rad(90))
		else
			crest.Size = Vector3.new(0.5, 1.1, 0.5) * s
			crest.CFrame = headPart.CFrame * CFrame.new(0, headSize * 0.6, 0)
		end
		if Rarity.tier(head.Rarity) >= 4 then
			crest.Material = Enum.Material.Neon
		end
	end

	-- Patrón: manchas del color del gen sobre el cuerpo.
	if pattern and pattern.Id ~= "pattern_plain" then
		local spots = 3 + Rarity.tier(pattern.Rarity)
		for i = 1, spots do
			local angle = (i / spots) * math.pi * 2
			local spot = part("Pattern", Enum.PartType.Ball, Vector3.new(0.9, 0.9, 0.9) * s, rgb(pattern.Color), model)
			spot.CFrame = bodyPart.CFrame
				* CFrame.Angles(0, angle, 0)
				* CFrame.new(0, (i % 2 - 0.5) * 0.6 * s, bodyPart.Size.X * 0.42)
			if Rarity.tier(pattern.Rarity) >= 4 then
				spot.Material = Enum.Material.Neon
			end
		end
	end

	-- Aura: partículas del color del gen.
	if aura and aura.Id ~= "aura_none" then
		local emitter = Instance.new("ParticleEmitter")
		emitter.Color = ColorSequence.new(rgb(aura.Color))
		emitter.LightEmission = 0.8
		emitter.Rate = 6 + 6 * Rarity.tier(aura.Rarity)
		emitter.Lifetime = NumberRange.new(0.8, 1.4)
		emitter.Speed = NumberRange.new(1, 3)
		emitter.SpreadAngle = Vector2.new(180, 180)
		emitter.Size = NumberSequence.new(0.3 * s, 0)
		emitter.Parent = bodyPart
	end

	-- Mutaciones visibles.
	if mutation == "mut_ghost" then
		for _, p in model:GetDescendants() do
			if p:IsA("BasePart") then
				p.Transparency = 0.45
			end
		end
	elseif mutation == "mut_shiny" or mutation == "mut_golden" then
		bodyPart.Reflectance = 0.35
	elseif mutation == "mut_glow" or mutation == "mut_cosmic" or mutation == "mut_rainbow" then
		bodyPart.Material = Enum.Material.Neon
	end

		model:SetAttribute("Rainbow", true) -- el cliente anima el color
	end

	if rarityInfo.Tier >= 3 then
		local light = Instance.new("PointLight")
		light.Color = rgb(rarityInfo.Color)
		light.Range = 6 + rarityInfo.Tier * 2
		light.Brightness = 1.5
		light.Parent = bodyPart
	end

	-- Etiqueta con nombre y rareza.
	local billboard = Instance.new("BillboardGui")
	billboard.Name = "Label"
	billboard.Size = UDim2.fromOffset(160, 40)
	billboard.StudsOffsetWorldSpace = Vector3.new(0, bodyPart.Size.Y + 1.5, 0)
	billboard.MaxDistance = 80
	billboard.AlwaysOnTop = false
	billboard.Parent = bodyPart
	local label = Instance.new("TextLabel")
	label.Size = UDim2.fromScale(1, 1)
	label.BackgroundTransparency = 1
	label.Font = Enum.Font.FredokaOne
	label.TextScaled = true
	label.TextColor3 = rgb(rarityInfo.Color)
	label.TextStrokeTransparency = 0.3
	label.Text = string.format("%s\n%s", model.Name, rarityInfo.DisplayName)
	label.Parent = billboard

	model:SetAttribute("CreatureId", creature.Id)
	model:SetAttribute("Rarity", creature.Rarity)
	return model
end

4.12 DataService · guardar sin duplicar

El problema clásico: un jugador sale de un servidor y entra en otro antes de que el primero termine de guardar. El segundo carga datos viejos, y si había un intercambio de por medio, aparecen criaturas duplicadas. La solución es un bloqueo de sesión: el perfil guardado lleva una marca con el JobId del servidor que lo tiene abierto.

sequenceDiagram participant A as Servidor A participant DS as DataStore participant B as Servidor B A->>DS: UpdateAsync: ¿bloqueado? no → Lock = A Note over A: El jugador juega en A B->>DS: UpdateAsync: ¿bloqueado? sí (A, reciente) → cancelar B-->>B: espera 4 s y reintenta A->>DS: Guardar y liberar (Lock = nil) B->>DS: UpdateAsync: libre → Lock = B ✔ 
-- Intenta abrir el perfil tomando el bloqueo. Devuelve nil si otro servidor lo tiene.
local function acquire(player: Player): (boolean, any)
	local s = store :: DataStore
	local locked = false
	local ok, raw = retry("cargar " .. player.Name, function()
		locked = false
		return s:UpdateAsync(key(player), function(old: any)
			if type(old) == "table" and type(old.Lock) == "table" then
				local lock = old.Lock
				local fresh = type(lock.Time) == "number" and now() - lock.Time < Config.Data.LockTimeoutSeconds
				if lock.JobId ~= game.JobId and fresh then
					locked = true
					return nil -- no escribir: otro servidor tiene la sesión
				end
			end
			local data = if type(old) == "table" then old.Data else nil
			return { Data = data, Lock = { JobId = game.JobId, Time = now() } }
		end)
	end)
	if not ok then
		return false, nil
	end
	if locked then
		return false, "locked"
	end
	return true, if type(raw) == "table" then raw.Data else nil
end

Devolver nil dentro de UpdateAsync cancela la escritura: así se comprueba y se toma el bloqueo en una sola operación atómica. Si el bloqueo es más antiguo que LockTimeoutSeconds ( s), se considera abandonado, por ejemplo porque el otro servidor se cayó.

local function write(player: Player, profile: Profile, release: boolean): boolean
	if useMemory then
		return true
	end
	local s = store :: DataStore
	profile.LastSeen = now()
	local written = false
	local ok = retry("guardar " .. player.Name, function()
		written = false
		return s:UpdateAsync(key(player), function(old: any)
			if type(old) == "table" and type(old.Lock) == "table" and old.Lock.JobId ~= game.JobId then
				return nil -- perdimos el bloqueo; no pisar datos de otro servidor
			end
			if not release and released[player] then
				return nil -- ya se guardó al salir; no reabrir la sesión
			end
			written = true
			return {
				Data = profile,
				Lock = if release then nil else { JobId = game.JobId, Time = now() },
			}
		end)
	end)
	return ok and written
end

Al guardar se vuelve a comprobar el bloqueo. Si otro servidor lo tiene, no se escribe, para no pisar sus datos. Al salir el jugador se guarda con release = true y se libera.

Cada operación se reintenta hasta 5 veces, con esperas cada vez más largas. Los DataStores pueden fallar de forma puntual.

Cada s se guardan todos los perfiles, para no perder mucho si se cae el servidor.

🛑 BindToClose

Cuando Roblox cierra el servidor, se guardan todos los perfiles. Hay como mucho unos 25 s para hacerlo.

📤 markChanged

Marca el perfil como "sucio". Cada 0,25 s se envía la vista actualizada al cliente, agrupando los cambios en un solo mensaje.

-- Copia común para el aliado de un trato: conserva los genes comunes de la criatura y
-- cambia el resto por genes comunes de la misma ranura.
function Genes.commonCopy(source: GeneSet, rng: () -> number): GeneSet
	local copy = table.clone(source) :: any
	for _, slot in Genes.Slots do
		local gene = Genes.ById[copy[slot]]
		if not gene or gene.Rarity ~= "Common" then
			copy[slot] = Genes.rollSlot(slot, rng, "Common")
		end
	end
	return copy
end
function RoundService.isBloodMoon(): boolean

local function setupBumpPrompt(player: Player, character: Model)
	local root = character:WaitForChild("HumanoidRootPart", 10)
	if not root then
		return
	end
	local prompt = Instance.new("ProximityPrompt")
	prompt.Name = "BumpPrompt"
	prompt.ActionText = "Empujar"
	prompt.ObjectText = "Bolsa llena"
	prompt.KeyboardKeyCode = Enum.KeyCode.F
	prompt.GamepadKeyCode = Enum.KeyCode.ButtonY
	prompt.HoldDuration = 0
	prompt.MaxActivationDistance = Config.Heat.BumpRange
	prompt.RequiresLineOfSight = false
	prompt.Enabled = false
	prompt.Parent = root

	prompt.Triggered:Connect(function(bumper)
		if bumper == player or not active then
			return
		end
		local victim = state(player)
		local now = os.clock()
		if now - victim.LastBumped < Config.Heat.BumpCooldown or victim.Heat < HeatService.capacity(player) then
			return
		end
		local bumperRoot = rootOf(bumper)
		local victimRoot = rootOf(player)
		if not bumperRoot or not victimRoot or (bumperRoot.Position - victimRoot.Position).Magnitude > Config.Heat.BumpRange + 3 then
			return
		end
		victim.LastBumped = now
		local dropped = math.floor(victim.Heat * Config.Heat.BumpDropFraction)
		victim.Heat -= dropped
		sync(player)
		dropEmbers(victimRoot.Position, dropped)
		victimRoot.AssemblyLinearVelocity += (victimRoot.Position - bumperRoot.Position).Unit * 40 + Vector3.new(0, 20, 0)
		AnnouncementService.player(player, string.format("¡%s te ha empujado! Se te cayeron %d de Calor.", bumper.DisplayName, dropped))
	end)

	player:GetAttributeChangedSignal("BagFull"):Connect(function()
		prompt.Enabled = player:GetAttribute("BagFull") == true and active
	end)
end

local function onStealTriggered(thief: Player)
	local current = carrier
	if not active or not current or thief == current then
		return
	end
	local now = os.clock()
	local began = holdStart[thief]
	holdStart[thief] = nil
	if (stunnedUntil[thief] or 0) > now then
		return -- aturdido o esperando la ventaja del elegido
	end
	-- El tiempo de pulsación lo mide el servidor: un cliente modificado no puede saltárselo.
	local atHome = NestService.isInsideOwnNest(current)
	local check = ChaseRules.canSteal(now, began, immuneUntil, distance(thief, current), atHome)
	if check == "immune" then
		AnnouncementService.player(thief, "¡El portador es inmune unos segundos!")
	end
	if check ~= "ok" then
		return
	end

	-- Escudo de Cáscara: bloquea un robo, como mucho uno por ronda.
	if (shieldCharges[current] or 0) > 0 and (shieldsUsed[current] or 0) < Config.Chase.ShieldsPerRound then
		shieldCharges[current] -= 1
		shieldsUsed[current] = (shieldsUsed[current] or 0) + 1
		immuneUntil = now + Config.Chase.ImmunityAfterSteal
		AnnouncementService.server(string.format("¡El Escudo de Cáscara de %s ha bloqueado un robo!", current.DisplayName), "info")
		return
	end

	if ChaseService.allied(current, thief) then
		deals[current][thief] = nil
		if deals[thief] then
			deals[thief][current] = nil
		end
		DataService.addStat(thief, "PactsBroken", 1)
		AnnouncementService.server(string.format("💔 ¡%s ha traicionado a %s!", thief.DisplayName, current.DisplayName), "rare")
	else
		AnnouncementService.server(string.format("¡%s le ha robado la criatura a %s!", thief.DisplayName, current.DisplayName), "info")
	end
	DataService.addStat(thief, "Steals", 1)
	QuestService.progress(thief, "Steal", 1)
	if Config.Chase.StunSeconds > 0 then
		stunnedUntil[current] = now + Config.Chase.StunSeconds
		AnnouncementService.player(current, string.format("¡Te la han robado! Aturdido %d s", Config.Chase.StunSeconds))
		updateSpeed(current)
	end
	ChaseService.setCarrier(thief)

local function updateSpeed(player: Player)
	local character = player.Character
	local humanoid = character and character:FindFirstChildOfClass("Humanoid")
	if not humanoid then
		return
	end
	local profile = DataService.get(player)
	local boots = if profile then profile.Upgrades.Boots else 0
	local now = os.clock()
	local sprinting = (sprintUntil[player] or 0) > now
	local stunned = active and (stunnedUntil[player] or 0) > now

	local root = rootOf(player)
	if active and root then
		local here = NestService.nestIndexAt(root.Position)

		intruding = here ~= nil and here ~= own
	end

	player:SetAttribute("Sprinting", sprinting)
	player:SetAttribute("Stunned", stunned)
	player:SetAttribute("Intruding", intruding)
end

-- Criaturas que libera "liberar guardadas": las que no producen (fuera de las `slots`
-- mejores) de rareza baja, empezando por las peores y sin bajar de KeepAtLeast en total.
function Economy.bulkReleaseIds(creatures: { Creature.Creature }, slots: number): { string }
	local sorted = Creature.sortByIncome(creatures)
	local maxTier = Rarity.tier(Config.Release.BulkMaxRarity :: Rarity.RarityName)
	local allowed = math.max(#sorted - Config.Release.KeepAtLeast, 0)
	local ids = {}
	for index = #sorted, slots + 1, -1 do
		if #ids >= allowed then
			break
		end
		local creature = sorted[index]
		if Rarity.tier(creature.Rarity) <= maxTier and Economy.releaseDust(creature.Rarity) then
			table.insert(ids, creature.Id)
		end
	end
	return ids
end

local function processReceipt(receipt: any): Enum.ProductPurchaseDecision
	local player = Players:GetPlayerByUserId(receipt.PlayerId)
	if not player then
		return Enum.ProductPurchaseDecision.NotProcessedYet
	end
	local profile = DataService.get(player)
	if not profile then
		return Enum.ProductPurchaseDecision.NotProcessedYet
	end
	local receiptId = tostring(receipt.PurchaseId)
	if PlayerData.hasReceipt(profile, receiptId) then
		return Enum.ProductPurchaseDecision.PurchaseGranted
	end
	local handler = handlers[receipt.ProductId]
	if not handler then
		warn("[MonetizationService] Producto sin handler: " .. tostring(receipt.ProductId))
		return Enum.ProductPurchaseDecision.NotProcessedYet
	end
	local ok, granted = pcall(handler, player)
	if not ok or not granted then
		return Enum.ProductPurchaseDecision.NotProcessedYet
	end
	PlayerData.addReceipt(profile, receiptId)
	if not profile.Funnel.FirstPurchase then
		profile.Funnel.FirstPurchase = true
	end
	DataService.markChanged(player)
	-- Guardar antes de confirmar: si el guardado falla, Roblox reintentará el recibo y el
	-- registro de recibos evitará entregarlo dos veces.
	if not DataService.saveNow(player) then
		return Enum.ProductPurchaseDecision.NotProcessedYet
	end
	return Enum.ProductPurchaseDecision.PurchaseGranted
end

4.24 HatchController · el espectáculo de 30 segundos

El momento pensado para grabarse. Se divide en tres actos con proporciones fijas sobre la duración que manda el servidor:

60 % · El huevo tiemblacámara orbitando, temblor creciente
30 % · Ruletafoco que se frena
10 %revelación
local function play(data: any)
	if running then
		return
	end
	running = true
	local duration = tonumber(data.Duration) or 30
	local order: { Candidate } = data.Order or {}
	local chosenId: number = tonumber(data.ChosenUserId) or 0
	local rarity: Rarity.RarityName = if Rarity.isValid(data.Rarity) then data.Rarity else "Common"
	local info = Rarity.Info[rarity]

	overlay.Visible = true
	captureButton.Visible = false
	local mine = 0
	for _, candidate in order do
		if candidate.UserId == player.UserId then
			mine = candidate.Chance
		end
	end
	chanceLabel.Text = string.format("Tu probabilidad: %.1f %%", mine * 100)

	-- Fase 1 (60 %): el huevo tiembla y la cámara orbita.
	local eggPart = egg()
	local originalCFrame = if eggPart then eggPart.CFrame else CFrame.new()
	camera.CameraType = Enum.CameraType.Scriptable
	local shakeEnd = os.clock() + duration * 0.6
	show("¿A QUIÉN ELEGIRÁ?", "El huevo se está agrietando...", UI.Colors.Accent)
	local angle = 0
	local connection = RunService.RenderStepped:Connect(function(dt)
		if not eggPart then
			return
		end
		angle += dt * 0.4
		local center = originalCFrame.Position
		camera.CFrame = CFrame.lookAt(center + Vector3.new(math.cos(angle) * 34, 14, math.sin(angle) * 34), center)
		local remaining = shakeEnd - os.clock()
		if remaining > 0 then
			local intensity = 0.15 + (1 - remaining / (duration * 0.6)) * 0.6
			eggPart.CFrame = originalCFrame * CFrame.Angles(
				math.rad(math.random(-10, 10) * intensity),
				0,
				math.rad(math.random(-10, 10) * intensity)
			)
		end
	end)
	task.wait(duration * 0.6)
	connection:Disconnect()
	if eggPart then
		eggPart.CFrame = originalCFrame
	end

	-- Fase 2 (30 %): ruleta con un foco que se va frenando hasta el elegido.
	local spot = makeSpotlight()
	local rouletteTime = duration * 0.3
	local steps = math.max(#order * 3, 12)
	local chosenIndex = 1
	for index, candidate in order do
		if candidate.UserId == chosenId then
			chosenIndex = index
		end
	end
	-- Ajusta el número de pasos para acabar exactamente en el elegido.
	if #order > 0 then
		steps += (chosenIndex - (steps % #order) - 1) % #order + 1
	end
	for step = 1, steps do
		local candidate = order[((step - 1) % math.max(#order, 1)) + 1]
		local root = candidate and rootOf(candidate.UserId)
		if root then
			placeSpot(spot, root.Position)
			camera.CFrame = CFrame.lookAt(root.Position + Vector3.new(0, 12, 18), root.Position)
			show(string.upper(candidate.Name), string.format("%.1f %%", candidate.Chance * 100), UI.Colors.Gold)
		end
		-- Intervalos crecientes: suspense al final.
		local t = step / steps
		local interval = (rouletteTime / steps) * (0.4 + 1.2 * t * t)
		task.wait(interval)
	end

	-- Fase 3: revelación.
	local chosenRoot = rootOf(chosenId)
	if chosenRoot then
		placeSpot(spot, chosenRoot.Position)
		camera.CFrame = CFrame.lookAt(chosenRoot.Position + Vector3.new(0, 8, 14), chosenRoot.Position)
	end
	spot.Color = UI.rgb(info.Color)
	local creatureName = tostring(data.CreatureName or "")
	if chosenId == player.UserId then
		show("¡EL HUEVO TE HA ELEGIDO!", string.format("%s (%s) · ¡Corre a tu nido!", creatureName, info.DisplayName), UI.Colors.Gold)
	else
		show(
			string.format("¡EL HUEVO ELIGE A %s!", string.upper(tostring(data.ChosenName or "?"))),
			string.format("%s (%s) · ¡Róbasela!", creatureName, info.DisplayName),
			UI.rgb(info.Color)
		)
	end
	captureButton.Visible = true
	task.wait(math.max(duration - duration * 0.9 - 0.2, 1.5))

	spot:Destroy()
	camera.CameraType = Enum.CameraType.Custom
	TweenService:Create(title, TweenInfo.new(0.5), { TextTransparency = 1 }):Play()
	task.wait(0.5)
	title.TextTransparency = 0
	overlay.Visible = false
	running = false
end

Dos detalles de la ruleta:

  • Termina siempre en el elegido. Se calcula cuántos pasos dar para que el último caiga justo sobre él.
  • Se va frenando. Los intervalos crecen de forma cuadrática (0.4 + 1.2·t²), igual que una ruleta real, y eso crea suspense.

El temblor del huevo es solo local: el cliente mueve su copia de la pieza y el servidor nunca se entera. Al final aparece un botón de captura que usa CaptureService.

			-- De 50 a 150 latidos por minuto.
			local bpm = 50 + 100 * fraction
			phaseTime += dt * bpm / 60
			local beat = math.max(0, math.sin(phaseTime * math.pi * 2)) ^ 6
			egg.Size = BASE_SIZE * (1 + beat * (0.03 + 0.05 * fraction))
		elseif egg and egg.Size ~= BASE_SIZE then
			egg.Size = BASE_SIZE
		end

		local hue = (os.clock() * 0.25) % 1
		for _, model in CollectionService:GetTagged("RainbowCreature") do
			local primary = if model:IsA("Model") then model.PrimaryPart else nil
			if primary then
				primary.Color = Color3.fromHSV(hue, 0.8, 1)
			end
		end
	end)
end

local function waypoint(agent: Agent, agents: { Agent }, target: Point, doorClosed: { [number]: number }, t: number): Point?
	local here = nestOf(agents, agent.Pos)
	local there = nestOf(agents, target)
	if here and here ~= there then
		-- salir por la entrada
		if (doorClosed[here] or 0) > t then
			return nil
		end
		local inner = nestInner(here)
		if dist(agent.Pos, inner) > 1.5 then
			return inner
		end
		return MapLayout.nestEntrance(here)
	end
	if there and here ~= there then
		local entrance = MapLayout.nestEntrance(there)
		if dist(agent.Pos, entrance) > 1.5 then
			return entrance
		end
		if (doorClosed[there] or 0) > t then
			return nil -- puerta cerrada: esperar fuera
		end
		return nestInner(there)
	end
	return target
end

4.29 Probar en Studio: piloto automático y depuración

El simulador comprueba el equilibrio, pero no puede encontrar fallos de Roblox: un prompt que no aparece, un remoto mal validado, un modelo que se cae del mapa. Para eso hay un modo de prueba que solo existe dentro de Studio. Con Test → Clients and Servers y 4 jugadores, Player1 eres tú y el resto juegan solos. La guía completa y la lista de comprobación están en docs/PRUEBAS.md.

Todo pasa por Testing. Como RunService:IsStudio() es falso en un servidor publicado, no hay forma de activar nada de esto desde fuera, aunque alguien dispare el remoto a mano.

function Testing.enabled(flag: Flag): boolean
	return RunService:IsStudio() and (Config.Testing :: any)[flag] == true
end
-- Duración de una fase: en Studio se acorta con Config.Testing.TimeScale para probar rápido.
function Testing.duration(seconds: number): number
	if RunService:IsStudio() then
		return math.max(seconds * Config.Testing.TimeScale, 5)
	end
	return seconds
end

El piloto automático no es un bot aparte: mueve el personaje con Humanoid:MoveTo y pulsa los mismos ProximityPrompts que una persona con InputHoldBegin/InputHoldEnd. El servidor mide el tiempo de pulsación igual que siempre, así que un robo del piloto pasa por la misma validación que uno real.

-- Mantiene pulsado un prompt real durante unos segundos (como una persona con la tecla E).
local function hold(prompt: ProximityPrompt, seconds: number)
	if holding == prompt then
		return
	end
	if holding then
		holding:InputHoldEnd()
	end
	holding = prompt
	holdUntil = os.clock() + seconds
	prompt:InputHoldBegin()
end

Cada 0,25 s decide qué hacer según la fase. Si lleva 2,5 s sin moverse (un árbol, una pared), salta y descarta ese objetivo durante 8 s.

local function chase(root: BasePart)
	if player:GetAttribute("IsCarrier") then
		release()
		local nest = player:GetAttribute("NestPosition")
		if typeof(nest) ~= "Vector3" then
			return
		end
		-- ¿Hay ladrones cerca?
		local nearest = math.huge
		for _, other in Players:GetPlayers() do
			local r = if other ~= player then rootOf(other) else nil
			if r then
				nearest = math.min(nearest, flat(r.Position, root.Position))
			end
		end
		if nearest < 15 then
			Remotes.event("RequestSprint"):FireServer()
		end
		local atHome = flat(nest, root.Position) < Config.Nest.Count -- ~dentro de la parcela (26 studs)
		if atHome then
			local round = tonumber(RoundState.get("Round")) or 0
			if nearest < 22 and doorUsedRound ~= round then
				doorUsedRound = round
				Remotes.event("RequestCloseDoor"):FireServer()
			end
			-- Moverse dentro del nido para esquivar.
			moveTo(nest + Vector3.new(math.random(-8, 8), 0, math.random(-8, 8)))
		else
			moveTo(nest)
		end
		return
	end

	local carrierId = RoundState.get("CarrierUserId")
	local carrier = if type(carrierId) == "number" and carrierId ~= 0 then Players:GetPlayerByUserId(carrierId) else nil
	local carrierRoot = carrier and rootOf(carrier)
	if not carrierRoot then
		-- Criatura suelta: ir a por ella y recogerla.
		local creature = workspace:FindFirstChild("RoundCreature")
		if creature and creature:IsA("Model") then
			moveTo(creature:GetPivot().Position)
			local body = creature.PrimaryPart
			local prompt = body and body:FindFirstChildOfClass("ProximityPrompt")
			if prompt and flat(creature:GetPivot().Position, root.Position) < 8 then
				hold(prompt, prompt.HoldDuration + 0.2)
			end
		end
		return
	end
	moveTo(carrierRoot.Position)
	local distance = flat(carrierRoot.Position, root.Position)
	local prompt = carrierRoot:FindFirstChild("StealPrompt")
	if prompt and prompt:IsA("ProximityPrompt") and distance < Config.Chase.StealRange - 1 then
		hold(prompt, prompt.HoldDuration + 0.2)
	elseif holding and distance > Config.Chase.StealRange then
		release()
	end
end
